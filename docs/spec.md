# kidori 仕様書（第1版）

家具づくりで使う板材（合板など）から、部材を歩留まり良く切り出すための **木取り計算システム**。

## 1. 概要

- 部材の仕上がり寸法を入力すると、パネルソーで切る寸法（木取り寸法）に変換し、定尺板への並べ方・必要な板の枚数・歩留まりを計算する。
- 利用者：自分と職場の人たち
- 利用環境：スマートフォン（iPhone / Android）
  - ブラウザで動く Web アプリとして作る。ホーム画面に追加してアプリのように使える形にする

## 2. 用語

| 用語 | 意味 |
|---|---|
| 板 | 切り出す元の定尺材（例：ラワン 18mm 3×6） |
| 部材 | 板から切り出すパーツ（例：天板、側板、棚板） |
| 仕上がり寸法 | 家具として完成したときの部材の寸法 |
| 逃げ | 納まりを良くするためのクリアランス。設定画面に登録し、式の中で引く（例：`天地板.W - 逃げ1mm`） |
| 切り代 | 仕上がり寸法に足す、あとで削り仕上げるための余分 |
| 木取り寸法 | パネルソーで切る寸法（仕上がり寸法＋切り代） |
| 刃厚 | 1回切るごとに刃で削れて消える幅 |
| 端切り | 材料の端を最初に切り落とし、矩（直角）を出すこと |
| 歩留まり | 板の面積のうち、部材として使えた面積の割合（木取り寸法の面積 ÷ 板全体の面積） |

## 3. 全体の流れ

```
① 部材を入力（寸法は数値または式。逃げ・材料の厚みも式に入れられる）
      ↓ 式を計算する
② 仕上がり寸法
      ↓ 切り代を足す
③ 木取り寸法 ……（②③を「寸法表」として単独でも見られる）
      ↓ 材料名＋厚みごとに分けて計算
④ 木取り計算（配置図・切る順番・歩留まり・端材・必要枚数）
```

## 4. 設定（仕事ごと。新しい仕事は初期値から）

| 項目 | 初期値 | 備考 |
|---|---|---|
| 刃厚 | 3mm | 変更できる |
| 端切り | 5mm | 変更できる。この幅は刃厚を含む。どの辺を落とすかは切り方による（下記） |
| 切り代 | 10mm | 選択または入力できる。**材料グループの部材だけに足す**（材料の部材は 0）。部材ごとに上書きできる |
| 切り方 | 縦切り優先 | 縦切り優先 / 横切り優先 / おまかせ から選ぶ |

### 設定の引き継ぎ（第2.5.1版で変更）

- 設定（材料・材料グループ・調整寸法・刃厚・端切り・切り代・切り方）は仕事ごとに持つ
- **新しい仕事・見本は、いつも初期値の設定から始める**（前の仕事の設定は引き継がない）。初期値は下の表、調整寸法 逃げ0.5・逃げ1、材料は 5.1 の「最初から入っている材料」、材料グループはなし
  - 見本は、初期値の設定に、見本で使うもの（フラッシュ25 と芯材15 など）を足して作る。見本は **フラッシュ25 と ラワン4mm だけ** で作る家具にする
- **仕事をコピーしたときは、元の仕事の設定をそのまま引き継ぐ**
- **最初から入っている材料は、今ある全部の仕事にも自動で足す**（アプリを開いたとき、材料名＋厚みが同じ材料が無ければ足す。今ある材料・部材・計算結果は変えない）。最初から入っている材料は今後増える前提
  - その仕事でユーザーが削除した最初の材料は、仕事ごとに覚えておき、自動では足し直さない

### 設定画面の一覧（逃げ・材料）

- 調整寸法と材料の一覧は **同じ見た目・同じ操作** にそろえる（1行ずつ：名前・編集・削除。上に追加の入力）
- どちらも **一括削除** ができる（選ぶモードにして、チェックしたものをまとめて削除。使っている部材があれば示して確認する）

### 調整寸法（旧：逃げ）

- 逃げ・ほぞなど、本来の仕上がり寸法に対して **伸ばしたり短くしたりする寸法** を登録する項目
- 1つの調整寸法は **名前と寸法** を持つ（例：名前「逃げ」寸法 1、名前「ほぞ」寸法 15）。寸法は 0 より大きい値
- 画面や式では「名前＋寸法」で表示する（例：逃げ1、ほぞ15。「mm」は付けない）
- 同じ名前でも寸法が違えば別の項目として登録できる（逃げ0.5 と 逃げ1）。名前と寸法の両方が同じものは重ねて登録しない
- 表示名（名前＋寸法）が同じになるものは登録できない（例：名前「逃げ1」寸法 5 と 名前「逃げ」寸法 15 はどちらも「逃げ15」になるため不可）
- 式の中で足すか引くかは、式に書く（例：`天地板.W - 逃げ1`、`棚板.D + ほぞ15`）
- 新しい仕事（初期値）には 逃げ0.5・逃げ1 が入っている。以前の「逃げ」は名前「逃げ」の調整寸法として引き継ぐ
- 名前・寸法はあとから変えられ、使っている式の表示と値もついてくる
- 式で使っている調整寸法を削除するときは、使っている部材を示して確認する

### 材料と材料グループ（第2.5版で、フラッシュを材料グループにまとめる）

材料は大きく2つのくくりで管理する。

| くくり | 中身 | 例 |
|---|---|---|
| **材料** | 材料名・厚み・木取りする／しない | ラワン4、メラミン1、ラワン18、芯材12（木取りしない） |
| **材料グループ** | 名前・中身の一覧（材料 × 枚数） | フラッシュ25、ベタ20 |

- **材料**に「**木取りしない**」を付けられる（例：芯材12。桟の枠など、パネルソーで切らないもの）。木取りしない材料は、厚みの計算には使うが、片を作らない
- **材料グループ**は、材料を組み合わせたもの。中身は「材料 × 枚数」を並べるだけで、**順番や「芯材・表面材」の区別は持たない**
  - 例：フラッシュ25 ＝ 芯材15×1 ＋ メラミン1×2 ＋ ラワン4×2（芯材15 は木取りしない）
  - 例：ベタ20 ＝ ラワン18×1 ＋ メラミン1×2（全部木取りする）
  - 厚みは中身の合計を自動で計算する
  - 材料グループの中に、材料グループは入れられない
- 材料グループの編集の中からは、新しい材料を足せない（先に「材料」の段で足す）
  - 同じ材料を2行に分けて入れない（枚数でまとめる）
- 材料グループを追加するとき、初めの形を選べる
  - **フラッシュ**：木取りしない材料（空欄）×1 ＋ メラミン1×2 ＋ ラワン4×2
  - **ベタ**：材料（空欄）×1 ＋ メラミン1×2
  - **空**：中身なし
- 名前は「初めの形の名前＋合計の厚み」を自動で入れる（例：ベタ20。「空」の形は「グループ20」）。中身を変えると名前もついてくる。手で書き換えたら、その名前を使う
- **切り代**（設定）は、**材料グループの部材すべて** に足す。材料の部材は 0（部材ごとに上書きしない限り）
- 部材の「材料」の欄では、材料と材料グループを **2つに分けて** 並べる。厚みの判定・式の厚みボタンは、材料グループなら合計の厚みを使う
- 材料グループの部材は、**木取りする中身ごと** に片を作る（例：ベタ20 の側板2枚 → ラワン18 を2枚・メラミン1 を4枚）。片は、同じ材料のほかの部材と一緒に並べる
- 寸法表では、材料グループの部材の厚みの数字を押すと、中身の内訳を出す（例：ベタ20（ラワン18×1 ＋ メラミン1×2））
- 材料を削除するときは、それを使っている部材と材料グループを示して確認する（削除すると、材料グループの中身からも外れる）
- **編集は設定画面で行う**。部材の画面からも行き来しやすくする
  - 材料の欄の横に「**編集**」。押すと設定の該当の材料（材料グループ）が開き、保存すると部材の画面に戻る
  - 選択肢の最後に「**＋ 材料グループを作る**」。設定の追加画面に飛び、作り終えると部材の画面に戻って、その材料グループが選ばれた状態になる
- **今のフラッシュは、材料グループに移す**：芯材の厚みは「芯材◯」（木取りしない材料）として材料に加えて使う（同じ厚みの芯材があればそれを使う）。表面材は中身に移す。名前・厚み・式・寸法・計算結果は変わらない

### 重ね切り（第2.6版で新しい決まりに変える）

- 第2.5版までは、材料グループごとに「重ねて切る」を設定し、木取りする中身が2種類で枚数が同じときだけ、2種類を1枚ずつ重ねていた
- **第2.6版からは、重ね切りは仕事ごと**：木取り画面の「**重ね切り（2枚重ね）**」の オン／オフ で切り替える（新しい仕事・見本はオン。仕事のコピーは元の仕事のまま）。材料グループの「重ねて切る」はなくす
- どの片を重ねるか・端材の使い方は 10.9「新しい重ね切り」の決まりに従う（材料グループの部材の、違う材料どうしだけを重ねる。**同じ材料どうしは重ねない**）
- **以前の仕事**：材料グループで「重ねて切る」を外していた（重ねられたのに外していた）仕事は、重ね切りを **オフ** にして読み込む。ほかの仕事は **オン**
- **2枚重ね**：違う材料を1枚ずつ重ねて（例：メラミン1枚＋ラワン1枚）、1回で切る。フラッシュ1枚分（メラミン2・ラワン2）は2回に分けて切る
- 木取り画面のまとめでは、重ね切りの分は **重ね切りの組の行だけ** に出す（例：「2枚重ね：メラミン1＋ラワン4」。メラミン・ラワンそれぞれの行に重ね切りの枚数を足して出さない）。材料の行には、その材料をふつうに木取りする分だけを出す
- 木取りでは、重ねる2種類の材料を **1つの配置図**（重ねた板）で並べる。その配置図1枚は、それぞれの材料1枚ずつを使う（必要な材料の枚数は、両方の材料に数える）
- 重ねた配置図には、重ねて切る部材だけを並べる（ほかの部材は並べない）
- 切り出しチェックは、重ねた1片につき1回で、2種類の両方に付く
- 重ねる2枚は **同じサイズの材料** で、組として **3×6 か 4×8** を選ぶ（**自由入力・手持ちは使えない**。9章）。組のサイズと、同じ材料をふつうに木取りする分のサイズは別々に選べる
- 以前の版のデータで、組の行が自由入力・手持ちになっているものは、読み込むときにその設定を外す（組の板は 3×6／4×8 のどちらか）。第2.6版からは、サイズがそろわないことを理由に重ね切りを外して知らせることはしない

### 切り方

パネルソーを前提に、すべて **端から端まで一直線に切る（ギロチンカット）** 並べ方にする。

- **縦切り優先**：材料を縦長に置く（長手が縦、妻手が上下）。右側の長手を端切りし、右から長手方向の帯を切り出して、その帯を切り分ける。縦長の端材が残りやすい
- **横切り優先**：材料を横長に置く（妻手が右）。**長手（下側）を端切りしてから、右側の妻手も端切りして矩を出す**。部材は右上から詰める。右から妻手方向の帯（妻手の幅いっぱい）を切り出して切り分けるので、長手がだんだん短くなり、妻手の幅のままの余りが左に残る
- どちらの切り方でも、部材は **右上から左下へ** 詰め、最終的な端材は左下に残る
- **おまかせ**：両方を計算し、必要な板が少ないほうを採用する。同じなら、一番大きい端材が大きいほう（端材を活かしやすいほう）を採る

## 5. 入力項目

### 5.1 板（材料）

| 項目 | 例 | 備考 |
|---|---|---|
| 材料名 | シナ合板 | |
| 厚み | 18mm | |

- 設定画面で登録するのは **材料名と厚みだけ**。サイズ（3×6／4×8／自由入力）と木目の方向は **木取り画面で材料ごとに選ぶ**（9章）

- 材料名＋厚みの組み合わせで板を区別する（例：シナ 18mm と ラワン 18mm は別の板）
- 初めて使うときの材料（最初から入っている材料）：ラワン 2.5・3・4・5.5・9・12・15・18・21・24・30、シナ 2.5・3・4・5.5・9・12・15・18・21・24・30、ポリ 2.5・4、メラミン 1（mm）。ランバーと積層は分けず、材料名と厚みで区別する。選ぶ画面は材料名ごとにまとめて見やすくする
- 材料を追加するとき、厚みの初期値は空欄（入力しないと追加できない）
- 材料が並ぶ場所（部材の編集の材料の選択、式の材料の厚みボタン、設定画面の材料の一覧）では、**あとから追加した材料を追加した順に上から並べ**、最初から入っている材料はその下に並べる
- 式のボタンや式の表示では、材料の厚みを「ラワン4」のように「mm」を付けずに出す
- 板は追加・削除できる。部材が使っている板を削除するときは、使っている部材名を示して確認する

### 5.2 部材

寸法は家具として組み立てたときの向きで、**W（幅）・H（高さ）・D（奥行き）** で入力する。

| 項目 | 例（側板） | 備考 |
|---|---|---|
| 名前 | 側板 | 式の中で参照に使うため、仕事の中で重複不可 |
| 材料名 | シナ合板 | 板の材料名と対応させる |
| W | 18 | 数値または式 |
| H | `全体.H - 天板.H` | 数値または式 |
| D | 600 | 数値または式 |
| 厚みの寸法 | W | W / H / D のどれが板の厚みにあたるか（5.3 参照） |
| 枚数 | 2 | |
| 木目 | H方向 | 板の面になる2つの寸法のどちらに木目を通すか。または「どちらでもよい」 |
| メモ | 切り出したあとに穴あけ | 切り出した後に必要な加工などを書いておく（任意） |
| 切り代 | （空欄） | mm。空欄なら仕事の初期値を使う |

- 部材は10種類以上、合計で100枚を超えることもある前提で作る

部材の例：

| 部材 | W | H | D | 厚みの寸法 | 板の面 | 木目の選択肢 |
|---|---|---|---|---|---|---|
| 天板 | 900 | 18 | 600 | H | W×D | W方向 / D方向 / どちらでもよい |
| 側板 | 18 | 700 | 600 | W | H×D | H方向 / D方向 / どちらでもよい |
| 背板 | 900 | 700 | 4 | D | W×H | W方向 / H方向 / どちらでもよい |

### 5.3 厚みの寸法の判定

- W・H・D のうち、材料の厚みと同じ値の寸法を自動で「厚みの寸法」として選ぶ
- 違っていれば手で選び直せる（例：細い桟で、厚みが一番小さい寸法とは限らない場合）
- 厚みの寸法の値が材料の厚みと一致しない場合（自動で一致する寸法が見つからない場合を含む）は **エラー** とし、部材を保存できないようにする（枚数0の行は除く）
- 部材の編集画面では、厚みの寸法はふだん「厚み：W（自動）」のように **表示するだけ**。材料の厚みと同じ値の寸法が2つ以上あって自動で決めきれないとき、厚みと同じ寸法が無いとき、手で選んである部材のときだけ、選ぶ欄を出す

### 5.4 入力のしやすさ

- 寸法（W・H・D）の入力中は、式の欄とボタンが画面の見やすい位置に来るよう自動でスクロールする。式の欄の上の1行に、ふだんは仕上がりの値、エラーのときは同じ行にエラーを赤で出す（1行に切り詰め、押すと全文）。式の下に別のエラーの行は作らない（エラーが出ても消えてもボタンの位置がずれないように）
- 式のボタンに出す材料の厚みは、**その部材で選んでいる材料の厚みだけ**にする
- 式のボタンで部材の寸法を入れるときは、**まず部材名を選び、次に W・H・D を選ぶ2段階** にする（部材が多くても、式の欄とボタンが画面に収まるように）
- 部材の寸法・材料の厚み・調整寸法のボタンは、**「部材｜厚み｜調整寸法」のタブで切り替える1つの欄** にまとめる。欄の高さは決めておき（部材名が2段ほど）、多いときは欄の中でスクロールする。最初は「部材」（ほかの部材が無ければ「厚み」）。375×667 の画面で、部材が20あっても式の欄とボタンが収まること
- 部材の材料（またはフラッシュ）を変えたとき、その部材の式に **前の材料の厚み** が入っていれば、**新しい材料の厚みに自動で置き換える**（例：フラッシュ25 → フラッシュ22）。置き換えたときは「W の式のフラッシュ25 をフラッシュ22 に置き換えました」と知らせ、元に戻せるようにする。ほかの部材の式は変えない
- 寸法（W・H・D）の入力は **ボタンだけで行う**。入力欄を押してもスマホのキーボードは出さない（ボタンとキーボードが両方出て使いにくいため）
  - 入力欄の下のボタンで式を作る
    - 登録済みの部材の寸法（例：`全体.W`、`側板.W`）
    - 材料の厚み（例：`ラワン4mm` の厚み）。材料の厚みを変えると、それを使った式もついてくる
    - 逃げ（例：`逃げ1mm`）
    - 数字、`+` `-` `×` `÷` `( )`、1字消す・全部消す
  - **左右ボタンで、式の中の入力位置（カーソル）を移動できる**。部材の寸法などの参照は1つの塊として移動・削除する
- 部材名・メモなど文字の入力欄は、ふつうのキーボードで入力する

## 6. 式

- W・H・D には、数値の代わりに式を書ける
- ほかの部材の寸法を `部材名.W`、`部材名.H`、`部材名.D` で参照できる
- 材料の厚みと、設定画面の逃げも参照できる（書き方は設計で決める。材料の厚みや逃げの寸法を変えたら、参照している式の値も変わること）
- 使える記号：`+` `-` `*` `/` `( )`
- 全角の数字・記号・英字（`９００` `＋` `－` `（ ）` `．` `Ｗ` など）や、`×` `✕`（掛ける）・`÷`（割る）・`−` `–` `—`（引く）も書ける。計算の前に半角の記号に置き換える（例：`９００×2` → `900*2`、`全体．Ｗ` → `全体.W`）。全角の空白も空白として扱う
  - 長音の `ー` は部材名に使うため、引き算の記号には置き換えない
  - 部材名は全角・半角の違いを区別しない（`棚板１` と `棚板1` は同じ名前とみなす）
- 例：
  ```
  全体：W 900、H 720、D 600
  天板：W = 全体.W、H 18、D = 全体.D
  側板：W 18、H = 全体.H - 天板.H、D = 全体.D
  棚板：W = 全体.W - 側板.W * 2、H 18、D = 全体.D - 20
  ```
  - 「全体」のように、切り出さない寸法だけの行（枚数 0）も置けるようにする
- 参照先の寸法を変えると、参照している部材の寸法も自動で変わる
- 参照したときに使う値は、その部材の仕上がり寸法（式の計算結果）とする
- 次の場合はエラーとして知らせる
  - 存在しない部材名を参照している
  - 循環参照になっている（A が B を参照し、B が A を参照する など）
  - 計算結果が 0 以下になる

## 7. 寸法の計算

```
仕上がり寸法 = 入力値（式の計算結果。逃げは式の中で引く）
木取り寸法   = 仕上がり寸法 ＋ 切り代
```

- 切り代は、板の面になる2つの寸法それぞれに合計で足す（例：フラッシュの天板 仕上がり W900×D600、切り代 10mm → 木取り 910×610）
- 設定の切り代は **材料グループの部材だけ** に足す。材料の部材は、部材ごとに上書きしない限り切り代 0（仕上がり寸法＝木取り寸法）
- 厚みの寸法には切り代を足さない

## 8. 木取り計算

- 木取り画面で切り出しをチェックした片は、固定した1枚として扱い、残りの部材だけを並べ直す（9章）。以前の版で部材ごとに付けた木取り済みは、計算から除いたまま残し、「外す」で戻せる

- 材料名＋厚みごとに分けて計算する
- 条件
  - 刃厚を切るたびに差し引く
  - 端切りの分を差し引く（縦切り優先：右側の長手。横切り優先：下側の長手と右側の妻手）
  - **木取りは右側（端切りをした辺）から順に行う**。部材は右から詰めて並べ、余りは左側に残す
  - 帯の中では、部材を配置図の上側から詰める。部材は **右上から左下に向かって** 埋まっていき、最終的な端材は左下に残る
  - 切る順番の寸法は、その時点で残っている板の端から測る（例：2本目の帯も「右端から 410mm」）
  - 木目の指定を守る
    - 部材の木目の方向を、板の木目の方向（5.1）に合わせて並べる
    - 「どちらでもよい」の部材は回転して置いてよい
  - 選んだ切り方（縦切り優先・横切り優先・おまかせ）に従う
- **同じ幅の部材を優先して縦に並べる**：同じ幅の帯に入れ、無ければ新しい帯を横に作り、板の幅が埋まったら、それまでの部材の下（幅の違う帯の残りの長さ）に入れる
  - ただし、この並べ方で **必要な板が増えるときは、今までの並べ方**（幅が収まる最初の帯に入れる）を使う。両方を計算して、板の枚数が少ないほうを使う（同じなら同じ幅を優先するほう）
- 1枚に入りきらない場合は、必要な板の枚数を算出し、2枚目以降にも割り振る
- 部材が100枚を超えても、スマホで数秒以内に結果を出す
  - 数学的に最適な並べ方の保証はしない。実用上良い並べ方を素早く出す

## 9. 結果の表示（すべてスマホで見られること）

- **材料のサイズの選択**（木取り画面のまとめ）：まとめの行ごと（材料の行・重ね切りの組の行それぞれ）に、3×6・4×8・自由入力 から選ぶ。3×6 と 4×8 は両方で木取りを計算して、必要な枚数と歩留まりを並べて見せる。選んだものは仕事に保存する。初期値は 4×8
  - 重ね切りの組の行の初期値（第2.6版）：2つの材料の行がどちらも同じ 3×6（または 4×8）を選んでいればそのサイズ、そうでなければ（違うサイズ・手持ちのとき）4×8
  - 例：「2枚重ね：メラミン1＋ラワン4」は 3×6、「ラワン4」（背板だけ）は 4×8、のように別々に選べる
  - **自由入力** を選ぶと、その行の **手持ちの材料** を登録する（サイズと枚数を複数。例：4×8 ×3枚、3×6 ×2枚、900×450 ×1枚）。手持ちの材料の欄を別に置かない
- **手持ちの材料**（自由入力の中身）：サイズごとに木目の方向も持つ
  - 手持ちの行の表示：その行を1枚も使わないときは「**不採用**」（赤字）、使うときは「**採用**」「**◯枚採用**」（青字）（部材が入らないことは、サイズのボタンの「**部材が収まらない**」で示す）、一部を使うときは「**◯枚採用**」、全部使うときは「**採用**」
  - 手持ちを登録した材料は、その範囲で木取りする。**大きい部材から順に、それが収まる一番小さい材料を選んで** 並べていく（小さい材料を無駄なく使い、歩留まりを良くする）
  - 配置図には、1枚ごとに使った材料（4×8・3×6・900×450 など）を出す
  - **足りないとき** は「◯◯が足りません（入らない部材：…）」と知らせ、解決策を出す：3×6・4×8 をそれぞれ何枚足せば全部入るか、切り代・端切りを小さくすれば手持ちで入るか（今の「材料を減らせるときのお知らせ」と同じ考え方）
  - 手持ちを登録しない材料は、今までどおりサイズを1つ選んで、足りるだけ使う
  - 重ね切りの組には手持ち（自由入力）を使わない。組の行は 3×6／4×8 だけを選ぶ
  - 固定した1枚は、使った手持ちの1枚として数える
  - 重ねた板の端材は、その仕事の手持ちとして自動で加わる（第2.6版。10.9「新しい重ね切り」）。ほかの端材を手持ちに加えるのは、端材の管理（10.9）で検討する

- **寸法表**：部材ごとの仕上がり寸法・枚数（木取り寸法は寸法表に出さない。木取り画面で見る）
  - スマホで見ることを前提にする。横スクロールせずに読めること（1部材1行の表。表は画面の幅に収める）
- **配置図**：板ごとに、部材を並べた図（部材名・寸法を表示）
- **切る順番**：画面には出さない（計算は残す。切り出しチェックの並び順と残りの材料の計算に使う）
- **歩留まり**：板ごと・全体の歩留まり（%）
- **端材**：画面には出さない（第2弾で端材の管理を検討）
- **必要な板の枚数**：材料名＋厚みごと
- **材料を減らせるときのお知らせ**：端切りや切り代を小さくすると必要な材料の枚数が減る場合は、その条件を知らせる（例：「切り代を 7mm にすると、ラワン 4mm が 1 枚減ります」）。切り代や端切りを変えたら、お知らせもすぐに計算し直す。設定は自動では変えない
  - **切り代を優先して試す**。切り代で枚数が減らない材料についてだけ、端切りを試す（材料ごとに判断する）
  - 今の値から 1mm ずつ小さくして 1mm まで試し、最後に 0.5mm を試す（0mm は試さない）。例：切り代 10 → 9, 8, …, 1, 0.5
  - 枚数が減る値のうち **一番大きい値** を知らせる（元の値に一番近く、変える量が一番少ないもの）
  - 端切りと切り代を同時に変える組み合わせは試さない
- **寸法表の表**：1部材1行で、部材名・枚数・仕上がり寸法 W・H・D と「仕上がり 完了」のチェックを並べる（カード表示は廃止）。寸法の数字を押すと **内訳** を開閉できる
  - 内訳は式の各項と値だけを出す（例：`全体.W 900 − 側板.W 18 × 2`）。「= 結果」や「天地板.W の内訳」のような見出しの文言は付けない（結果は表の数字で分かるため）
  - フラッシュの部材の厚みの内訳は、厚みの数字を押したときに出す（例：`フラッシュ25（芯材15 ＋ メラミン1×2 ＋ ラワン4×2）`）。表の中に別の行は作らない
- **加工のチェック**
  - **仕上がりの完了**：寸法表の各行のチェックで付ける
  - **切り出し（木取り）の完了**：**木取り画面** で、**材料1枚ごと**（配置図のすぐ下）のチェックリストで付ける（例：1枚目：天地板 874×410 □、天地板 874×410 □、棚板 873×390 □ …）。ふつうの部材も、フラッシュの表面材も同じ形。寸法表の中には置かない
  - **1つ目の部材にチェックすると、その1枚の並べ方を固定する**（固定のボタンは作らない）。チェックした部材は配置図でグレーになり、ほかの部材の位置は変わらない
  - 配置図には、切り終わった分（端切り・ノコ厚・チェックした部材）を除いた **残りの材料** の大きさを表示する
  - **その1枚の部材すべてにチェックすると、その1枚は木取り画面から消える**（切り終わり）
  - チェックを外すとグレーが戻る。その1枚のチェックがすべて外れたら固定も外れ、今の部材で並べ直す
  - 固定している1枚は、部材を足したり設定を変えたりしても変わらない。足した部材は、固定していない材料に並べる
  - 固定した1枚の部材の寸法や枚数があとで変わったときは、その1枚に「部材が変わっています」と知らせる（固定は外さない）
  - 切り出しチェックの並び順は、その1枚で **切る順番に取り出される順**（1枚目から取っていく部材の順）にそろえる
  - 切り出しのチェックは **1片ごと**（材料1枚の中の部材1つずつ）。チェックしたものはグレーで表示する
- **メモ**：部材のメモを寸法表にも表示する（部材名の下に小さく。長いときは省略し、押すと全文）

- **説明文**は、ふだんは画面に出さない。各項目の見出しを押すと、その説明が浮かび上がる（もう一度押すか、ほかを押すと消える）

## 10. 保存

- 仕事（設定・板・部材）を保存し、あとで開き直せる
- 仕事の一覧から、新しい仕事を作る・開く・名前を変える・コピーする（似た家具を作るとき用）・削除する（確認つき）ができる
- 第1版では、各自のスマホの中に保存する
- 以前の版で部材ごとに入れていた逃げは、読み込むときに設定の逃げへ移し、その部材の式から引く形に書き換える
- 初めて開いたときは、仕事が1つもない空の状態から始める
- 試しに使えるよう、仕事の画面から見本（本棚 W900）を追加できる（任意。削除もできる）

## 10.5 バックアップと共有

### 共有（仕事ごと・ファイルで送る）
- 仕事の画面の各仕事に「**この仕事を送る**」を置く。押すと、その仕事だけのファイル（例：`本棚W900.kidori.json`）を作り、スマホの共有シート（LINE・メール・AirDrop・「ファイル」に保存など）で送れる
- ファイルには、その仕事（部材・設定）と、その仕事で使っている材料・フラッシュ・調整寸法を入れる。サーバーは使わない
- 受け取った人は、LINE などでファイルを「ファイル」に保存し、kidori の「**ファイルから取り込む**」で選ぶ。「共有された仕事：本棚 W900（部材 5種類・9枚）」と確認が出て、「**取り込む**」で自分の仕事に **コピーとして追加** する（今ある仕事は変えない）。「やめる」で何もしない
- 取り込んだあとは、送った人と受け取った人で別々に編集する（同期しない）
- 共有するときは、切り出しチェック（固定した1枚）と寸法表の「完了」のチェックを外して送る
- ファイルを持っている人は誰でも中身を見られる（送り先に注意する、と説明書に書く）

### バックアップ（全部・ファイル）
- 仕事の画面に「**バックアップを書き出す**」を置く。全部の仕事を、1つのファイル（例：`kidori-バックアップ-2026-09-28.json`）にし、共有シート（「ファイル」に保存・LINE など）で保存する
- 「**ファイルから取り込む**」（共有と同じボタン）で、バックアップのファイルを選ぶと、中身（仕事の数と名前）の確認が出て、「**追加する**」で今の仕事に足す（同じ仕事があっても上書きせずコピーとして足す）。切り出しの記録も含めて戻す
- （第2.5.1版で「最後に使った設定」はなくしたので、バックアップには入れない。以前の版のファイルに入っていても読み飛ばす）
- 壊れたファイル・kidori 以外のファイルは「読み込めませんでした」と出し、今のデータは変えない
- 以前の版で書き出したファイルも読めるようにする
- 作らないもの：リンクで送る、すべて置き換え、定期的なお知らせ、設定だけの共有

### 新しい重ね切り（決定。第2.6版で作る）

- 重ね切りのオン・オフは仕事ごと（4「重ね切り」）
- 重ねるのは **2枚まで**。順番は気にしない。材料・厚みが違っても重ねてよい（厚みの差の制限は設けない）。重ねる2枚の板は同じサイズ（組の行の 3×6／4×8。初期値は 9）
- 組にするのは、**同じ部材の片どうしだけ**（寸法・木目がいつも同じ。違う部材の片は、寸法が同じでも組にしない）
- 組を作る順番：
  1. 材料グループの部材で、**違う材料どうし** を組にする（例：フラッシュの メラミン＋ラワン、ベタの メラミン＋ラワン18）
  2. 残った片は重ねない
  - **同じ材料どうしは重ねない**（1枚に2つ取れない大きい部材でも重ねない。材料を直接選んだ部材の片は重ねない）
  - どの組も、**重ねない場合と比べて板が増えるなら重ねない**（自動で確かめる）。比べるのは、まず **入らない部材の数**（増えないこと）、次に **材料ごとの必要な枚数**（重ねた板は上下それぞれの材料に1枚と数える。端材から取った1枚は数えない）。枚数が同じなら、使う板の面積が増えないこと。重ねた板の端材はほかの部材に使うので、重ねて板が増えることは少ないが、増えるときは重ねない
- 重ねる組を先に並べ、**重ねた板の端材を、上下それぞれの材料の手持ちとして自動で加える**（幅・長さとも30mm以上。もう一度の端切りはしない。その仕事の中だけで使う）。重ねない部材は、**端材から先に** 取る（端材の中では入る一番小さいものから。端材が 3×6 より大きくても端材が先）。入る端材が無ければ、今の手持ちの決まり（入る一番小さい材料から）で取る
- 木取り画面の手持ちの一覧に、自動でできた端材も「端材 780×1800（重ねた板1から）」のように出す（消したり枚数を変えたりはできない）
- 配置図には「2枚重ね：メラミン1＋ラワン4」、端材から取る1枚には「重ねた板1の端材（メラミン1）」のように出す
