# kidori 仕様書（第1版）

家具づくりで使う板材（合板など）から、部材を歩留まり良く切り出すための **木取り計算システム**。

## 1. 概要

- 部材の仕上がり寸法を入力すると、パネルソーで切る寸法（木取り寸法）に変換し、定尺板への並べ方・必要な板の枚数・歩留まりを計算する。
- 利用者：自分と職場の人たち
- 利用環境：スマートフォン（iPhone / Android）
  - ブラウザで動く Web アプリとして作る。ホーム画面に追加してアプリのように使える形にする

## 2. 用語

| 用語 | 意味 |
|---|---|
| 板 | 切り出す元の定尺材（例：シナ合板 18mm サブロク） |
| 部材 | 板から切り出すパーツ（例：天板、側板、棚板） |
| 仕上がり寸法 | 家具として完成したときの部材の寸法 |
| 逃げ | 納まりを良くするためのクリアランス。仕上がり寸法から引く |
| 切り代 | 仕上がり寸法に足す、あとで削り仕上げるための余分 |
| 木取り寸法 | パネルソーで切る寸法（仕上がり寸法＋切り代） |
| 刃厚 | 1回切るごとに刃で削れて消える幅 |
| 耳落とし | 板の端を最初に切り落とすこと |
| 歩留まり | 板の面積のうち、部材として使えた面積の割合（木取り寸法の面積 ÷ 板全体の面積） |

## 3. 全体の流れ

```
① 部材を入力（寸法は数値または式、逃げ）
      ↓ 式を計算し、逃げを引く
② 仕上がり寸法
      ↓ 切り代を足す
③ 木取り寸法 ……（②③を「寸法表」として単独でも見られる）
      ↓ 材料名＋厚みごとに分けて計算
④ 木取り計算（配置図・切る順番・歩留まり・端材・必要枚数）
```

## 4. 設定（仕事ごと）

| 項目 | 初期値 | 備考 |
|---|---|---|
| 刃厚 | 3mm | 変更できる |
| 耳落とし | 5mm | 変更できる。板を縦長に置いたときの **右側の長辺1辺だけ** 落とす。この幅は刃厚を含む（サブロクなら使える幅は 905mm） |
| 切り代 | 10mm | 選択または入力できる。部材ごとに上書きできる |
| 切り方 | 縦切り優先 | 縦切り優先 / 横切り優先 / おまかせ から選ぶ |

### 切り方

パネルソーを前提に、すべて **端から端まで一直線に切る（ギロチンカット）** 並べ方にする。

- **縦切り優先**：先に長辺方向に帯状に切り、その帯を横に切り分ける。縦長の端材が残りやすい
- **横切り優先**：先に短辺方向に切り、その後で縦に切り分ける
- **おまかせ**：両方を計算し、必要な板が少ないほうを採用する。同じなら、一番大きい端材が大きいほう（端材を活かしやすいほう）を採る

## 5. 入力項目

### 5.1 板（材料）

| 項目 | 例 | 備考 |
|---|---|---|
| 材料名 | シナ合板 | |
| 厚み | 18mm | |
| サイズ | サブロク（910×1820） | サブロク / シハチ（1220×2440）/ 自由入力 |
| 木目の方向 | 長辺方向 | 板の木目がどちらの辺に沿って通っているか。初期値は長辺方向。自由入力のときは長辺・短辺から選べる |

- 材料名＋厚みの組み合わせで板を区別する（例：シナ 18mm と ラワン 18mm は別の板）
- 板は追加・削除できる。部材が使っている板を削除するときは、使っている部材名を示して確認する

### 5.2 部材

寸法は家具として組み立てたときの向きで、**W（幅）・H（高さ）・D（奥行き）** で入力する。

| 項目 | 例（側板） | 備考 |
|---|---|---|
| 名前 | 側板 | 式の中で参照に使うため、仕事の中で重複不可 |
| 材料名 | シナ合板 | 板の材料名と対応させる |
| W | 18 | 数値または式 |
| H | `全体.H - 天板.H` | 数値または式 |
| D | 600 | 数値または式 |
| 厚みの寸法 | W | W / H / D のどれが板の厚みにあたるか（5.3 参照） |
| 枚数 | 2 | |
| 木目 | H方向 | 板の面になる2つの寸法のどちらに木目を通すか。または「どちらでもよい」 |
| 逃げ | H：1 | mm。板の面になる2つの寸法それぞれに指定できる。仕上がり寸法から引く |
| 切り代 | （空欄） | mm。空欄なら仕事の初期値を使う |

- 部材は10種類以上、合計で100枚を超えることもある前提で作る

部材の例：

| 部材 | W | H | D | 厚みの寸法 | 板の面 | 木目の選択肢 |
|---|---|---|---|---|---|---|
| 天板 | 900 | 18 | 600 | H | W×D | W方向 / D方向 / どちらでもよい |
| 側板 | 18 | 700 | 600 | W | H×D | H方向 / D方向 / どちらでもよい |
| 背板 | 900 | 700 | 4 | D | W×H | W方向 / H方向 / どちらでもよい |

### 5.3 厚みの寸法の判定

- W・H・D のうち、材料の厚みと同じ値の寸法を自動で「厚みの寸法」として選ぶ
- 違っていれば手で選び直せる（例：細い桟で、厚みが一番小さい寸法とは限らない場合）
- 選んだ厚みの寸法の値が材料の厚みと一致しない場合は、確認を促す表示を出す

### 5.4 入力のしやすさ

- 式は、キーボードで部材名を打たなくても作れるようにする
  - 入力欄の下に **登録済みの部材の寸法（例：`全体.W`、`側板.W`）を選択肢として並べ**、押すだけで式に入る
  - `+` `-` `×` `÷` `( )` と数字も、ボタンで入れられる
  - キーボードでの直接入力もできる

## 6. 式

- W・H・D には、数値の代わりに式を書ける
- ほかの部材の寸法を `部材名.W`、`部材名.H`、`部材名.D` で参照できる
- 使える記号：`+` `-` `*` `/` `( )`
- 全角の数字・記号・英字（`９００` `＋` `－` `（ ）` `．` `Ｗ` など）や、`×` `✕`（掛ける）・`÷`（割る）・`−` `–` `—`（引く）も書ける。計算の前に半角の記号に置き換える（例：`９００×2` → `900*2`、`全体．Ｗ` → `全体.W`）。全角の空白も空白として扱う
  - 長音の `ー` は部材名に使うため、引き算の記号には置き換えない
  - 部材名は全角・半角の違いを区別しない（`棚板１` と `棚板1` は同じ名前とみなす）
- 例：
  ```
  全体：W 900、H 720、D 600
  天板：W = 全体.W、H 18、D = 全体.D
  側板：W 18、H = 全体.H - 天板.H、D = 全体.D
  棚板：W = 全体.W - 側板.W * 2、H 18、D = 全体.D - 20
  ```
  - 「全体」のように、切り出さない寸法だけの行（枚数 0）も置けるようにする
- 参照先の寸法を変えると、参照している部材の寸法も自動で変わる
- 参照したときに使う値は、**逃げを引いた後の仕上がり寸法** とする
- 次の場合はエラーとして知らせる
  - 存在しない部材名を参照している
  - 循環参照になっている（A が B を参照し、B が A を参照する など）
  - 計算結果が 0 以下になる

## 7. 寸法の計算

```
仕上がり寸法 = 入力値（式の計算結果） − 逃げ
木取り寸法   = 仕上がり寸法 ＋ 切り代
```

- 切り代は、板の面になる2つの寸法それぞれに合計で足す（例：天板 仕上がり W900×D600、切り代 10mm → 木取り 910×610）
- 厚みの寸法には切り代を足さない

## 8. 木取り計算

- 材料名＋厚みごとに分けて計算する
- 条件
  - 刃厚を切るたびに差し引く
  - 耳落としの分を板の右側の長辺から差し引く
  - **木取りは右側（耳落としをした辺）から順に行う**。部材は右から詰めて並べ、余りは左側に残す
  - 帯の中では、部材を配置図の上側から詰める。部材は **右上から左下に向かって** 埋まっていき、最終的な端材は左下に残る
  - 切る順番の寸法は、その時点で残っている板の端から測る（例：2本目の帯も「右端から 410mm」）
  - 木目の指定を守る
    - 部材の木目の方向を、板の木目の方向（5.1）に合わせて並べる
    - 「どちらでもよい」の部材は回転して置いてよい
  - 選んだ切り方（縦切り優先・横切り優先・おまかせ）に従う
- 1枚に入りきらない場合は、必要な板の枚数を算出し、2枚目以降にも割り振る
- 部材が100枚を超えても、スマホで数秒以内に結果を出す
  - 数学的に最適な並べ方の保証はしない。実用上良い並べ方を素早く出す

## 9. 結果の表示（すべてスマホで見られること）

- **寸法表**：部材ごとの仕上がり寸法・木取り寸法・枚数
  - スマホで見ることを前提にする。横スクロールせずに読めること（表を横に広げず、部材ごとにまとめて表示する）
  - **仕上がり寸法と木取り寸法をはっきり見分けられること**（見出し・並び・色で区別し、どちらの数字か迷わない）
- **配置図**：板ごとに、部材を並べた図（部材名・寸法を表示）
- **切る順番**：パネルソーで切る順番
- **歩留まり**：板ごと・全体の歩留まり（%）
- **端材**：残った端材のサイズ
- **必要な板の枚数**：材料名＋厚みごと

## 10. 保存

- 仕事（設定・板・部材）を保存し、あとで開き直せる
- 仕事の一覧から、新しい仕事を作る・開く・名前を変える・コピーする（似た家具を作るとき用）・削除する（確認つき）ができる
- 第1版では、各自のスマホの中に保存する
