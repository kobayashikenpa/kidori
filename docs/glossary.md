# 画面の用語一覧

画面に出る言葉と、その意味の一覧。オーナーが「現場の言い方」を確認し、決まったものから画面に反映する。

- **いまの言葉**：いま画面に出ている言葉
- **現場の言い方**：オーナーが決めた言葉（空欄と「そのまま」は、いまの言葉のまま）

## 仕事と入力

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕事 | 1つの家具（注文）ごとの入力のまとまり。板・部材・設定をまとめて保存する | |
| 部材 | 板から切り出すパーツ（側板、天地板、棚板など） | |
| 板 | 切り出す元の定尺材（例：シナランバー 18mm サブロク） | 材料 |
| 材料名 | 板の種類の名前（シナランバー、シナベニヤなど） | 材料 |
| 見本 | 最初から入っている例（本棚 W900） | |
| 全体（寸法だけの行） | 切り出さず、家具の外寸などの寸法だけを持つ行（枚数 0） | |
| W・H・D | 組み立てたときの 幅・高さ・奥行き | そのまま |
| 厚み／厚みの寸法 | W・H・D のうち、板の厚みにあたる寸法 | 厚み |
| 式 | ほかの部材の寸法を使った計算（例：`全体.W - 側板.W * 2`） | |
| 参照ボタン | 式に `全体.W` などを入れるボタン | |
| 枚数 | その部材を何枚切り出すか | |

## 寸法

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕上がり寸法 | 家具として完成したときの寸法（逃げを引いた後） | |
| 逃げ | 納まりを良くするためのすき間。仕上がり寸法から引く | |
| 切り代 | あとで削り仕上げるための余分。仕上がり寸法に足す | |
| 木取り寸法 | パネルソーで切る寸法（仕上がり寸法＋切り代） | |
| 寸法表 | 部材ごとの仕上がり寸法と木取り寸法の一覧 | |

## 板と木目

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| サブロク／シハチ | 910×1820／1220×2440 の定尺板 | 3×6／4×8 |
| 自由入力 | 定尺以外の大きさの板 | そのまま |
| 長辺／短辺 | 板の長い辺（1820）／短い辺（910） | 長手／妻手 |
| 木目 | 部材の木目をどの寸法の方向に通すか（例：H方向） | |
| 木目の方向（板） | 板の木目が 長辺方向 か 短辺方向 か | |
| どちらでもよい | 木目の向きを気にせず、回して置いてよい | |

## 木取りの計算

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 木取り | 板への部材の並べ方を決めること、またはその結果 | |
| 刃厚 | 1回切るごとに刃で削れて消える幅（初期値 3mm） | ノコ厚？ |
| 耳落とし | 最初に板の端を切り落として矩を出すこと（初期値 5mm、刃厚を含む） | 端切り |
| 切り方 | 縦切り優先／横切り優先／おまかせ のどれで並べるか | |
| 縦切り優先 | 先に板の長辺方向に長く切り出し、それを切り分ける | |
| 横切り優先 | 先に板の短辺方向に切り出し、それを切り分ける | |
| おまかせ | 両方を計算し、必要な板が少ないほう（同じなら端材が大きく残るほう）を選ぶ | |
| 帯 | 最初の切断で板から切り出す、細長い材。部材そのものではなく、ここからさらに部材を切り分ける（例：幅 410mm × 長さ 1820mm の帯から、側板 1810mm を取る） | |
| 片（へん） | 部材1枚ぶんの切り出し。枚数 2 の部材なら片が 2 つ | |

## 結果

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 配置図 | 板の上に部材を並べた図 | |
| 切る順番 | パネルソーで切る順番 | |
| 帯を切る | 板から帯を切り出す工程 | |
| 切り分け | 帯から部材を切り出す工程 | |
| 幅を揃える | 帯より細い部材を、部材の幅に切り揃える工程 | |
| 右端から／上端から ○mm | その時点で残っている板（帯）の端から測った位置 | |
| 端材 | 部材を取ったあとに残る、幅・長さとも 30mm 以上の余り | |
| 歩留まり | 板の面積のうち、部材（木取り寸法）に使えた割合 | |
| 必要な板 | 部材をすべて取るのに必要な板の枚数 | 必要な材料 |
| 板に入らない部材 | どう置いても板に入らない部材 | 材料に収まらない部材 |
| 計算から外した部材 | 板が未設定・寸法エラーなどで、木取りに入れなかった部材 | そのまま |
| 板が未設定 | 部材にまだ板が選ばれていない | |
