# 画面の用語一覧

画面に出る言葉と、その意味の一覧。オーナーが「現場の言い方」を確認し、決まったものから画面に反映する。

- **いまの言葉**：いま画面に出ている言葉
- **現場の言い方**：オーナーが決めた言葉（空欄と「そのまま」は、いまの言葉のまま）

## 仕事と入力

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕事 | 1つの家具（注文）ごとの入力のまとまり。板・部材・設定をまとめて保存する | |
| 部材 | 板から切り出すパーツ（側板、天地板、棚板など） | |
| 板 | 切り出す元の定尺材（例：ラワン 18mm サブロク） | 材料 |
| 材料名 | 板の種類の名前（ラワン、シナ、ポリ、メラミンなど） | 材料 |
| 見本 | 最初から入っている例（本棚 W900） | |
| 全体（寸法だけの行） | 切り出さず、家具の外寸などの寸法だけを持つ行（枚数 0） | |
| W・H・D | 組み立てたときの 幅・高さ・奥行き | そのまま |
| 厚み／厚みの寸法 | W・H・D のうち、板の厚みにあたる寸法 | 厚み |
| 式 | ほかの部材の寸法を使った計算（例：`全体.W - 側板.W * 2`） | |
| 参照ボタン | 式に `全体.W` などを入れるボタン | |
| 枚数 | その部材を何枚切り出すか | |

## 寸法

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕上がり寸法 | 家具として完成したときの寸法（式の計算結果。逃げは式の中で引く） | |
| 調整寸法（逃げ1・ほぞ15 など） | 仕上がり寸法を伸ばしたり短くしたりする寸法。設定画面に名前と寸法で登録し、式のボタンで入れて足し引きする（旧：逃げ） | |
| 材料の厚み（ラワン4・フラッシュ25 など） | 式に入れられる材料（材料グループは中身の合計）の厚み。厚みを変えると式の値もついてくる | |
| 切り代 | あとで削り仕上げるための余分。仕上がり寸法に足す。設定の切り代は材料グループの部材だけに足す | |
| 木取り寸法 | パネルソーで切る寸法（仕上がり寸法＋切り代。切り代は材料グループの部材だけ）。木取り画面で見る | |
| 寸法表 | 部材ごとの仕上がり寸法の一覧（表）。数字を押すと内訳が出る | |

## 板と木目

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| サブロク／シハチ | 910×1820／1220×2440 の定尺板 | 3×6／4×8 |
| 自由入力 | 定尺以外の大きさの板 | そのまま |
| 長辺／短辺 | 板の長い辺（1820）／短い辺（910） | 長手／妻手 |
| 木目 | 部材の木目をどの寸法の方向に通すか（例：H方向） | |
| 木目の方向（板） | 板の木目が 長辺方向 か 短辺方向 か | |
| どちらでもよい | 木目の向きを気にせず、回して置いてよい | |

## 木取りの計算

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 木取り | 板への部材の並べ方を決めること、またはその結果 | |
| 刃厚 | 1回切るごとに刃で削れて消える幅（初期値 3mm） | そのまま |
| 耳落とし | 最初に板の端を切り落として矩を出すこと（初期値 5mm、刃厚を含む） | 端切り |
| 切り方 | 縦切り優先／横切り優先／おまかせ のどれで並べるか | |
| 縦切り優先 | 先に板の長辺方向に長く切り出し、それを切り分ける | |
| 横切り優先 | 先に板の短辺方向に切り出し、それを切り分ける | |
| おまかせ | 両方を計算し、必要な板が少ないほう（同じなら端材が大きく残るほう）を選ぶ | |
| 帯 | 最初の切断で板から切り出す、細長い材。部材そのものではなく、ここからさらに部材を切り分ける（例：幅 410mm × 長さ 1820mm の帯から、側板 1810mm を取る） | |
| 片（へん） | 部材1枚ぶんの切り出し。枚数 2 の部材なら片が 2 つ | |

## 結果

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 配置図 | 板の上に部材を並べた図 | |
| 切る順番 | パネルソーで切る順番 | |
| 帯を切る | 板から帯を切り出す工程 | |
| 切り分け | 帯から部材を切り出す工程 | |
| 幅を揃える | 帯より細い部材を、部材の幅に切り揃える工程 | |
| 右端から／上端から ○mm | 切る順番の位置（画面には出さない。計算の中だけで使う） | |
| 端材 | 部材を取ったあとに残る、幅・長さとも 30mm 以上の余り（画面には出さない。第2弾で管理を検討） | |
| 歩留まり | 板の面積のうち、部材（木取り寸法）に使えた割合 | |
| 必要な板 | 部材をすべて取るのに必要な板の枚数 | 必要な材料 |
| 板に入らない部材 | どう置いても板に入らない部材 | 材料に収まらない部材 |
| 計算から外した部材 | 板が未設定・寸法エラーなどで、木取りに入れなかった部材 | そのまま |
| 板が未設定 | 部材にまだ板が選ばれていない | |

## 第1.1版で増えた言葉

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| メモ | 部材ごとに、切り出したあとに必要な加工などを書いておく欄 | |
| 完了（寸法表） | 寸法表の各行のチェック。その部材の仕上がり寸法の加工が終わったことを示し、行がグレーになる | |
| 切り出しチェック | 木取り画面で、材料1枚ごとに部材を切り出したら付けるチェック。1つ目でその1枚の並びが固定され、全部付けると「切り終わり」に移る | |
| 残りの材料 | 切り出しチェックを付けたあと、その1枚に残っている材料の大きさ | |
| 手持ちの材料 | 仕事で使える材料のサイズと枚数（3×6・4×8・自由入力を複数） | |
| 重ね切り | 材料グループの木取りする中身の2種類（例：メラミン1＋ラワン4）を2枚重ねて1回で切ること | |
| フラッシュ | 材料グループの初めの形の1つ（木取りしない材料×1＋メラミン1×2＋ラワン4×2。例：フラッシュ25＝芯材15×1＋メラミン1×2＋ラワン4×2）。第2.4版までの「フラッシュ」の登録は材料グループに移った | |
| お知らせ | 切り代や端切りを小さくすると必要な材料が減るときに、木取り画面に出る案内（設定は自動では変えない） | |
| ◀ ▶／1字消す／全部消す | 式の入力位置を動かす／直前の1つ（数字1字、または参照1つ）を消す／式を全部消す | |

## 第2.5版で増えた言葉

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 材料 | 材料名と厚みで区別する1種類の板（例：ラワン 4mm、芯材 15mm）。設定の「材料」の段で登録する。最初から25（ラワン・シナ 2.5〜30、ポリ 2.5・4、メラミン 1）。一覧・選ぶ欄は材料名ごとにまとめる | |
| 材料グループ | 材料を組み合わせて名前を付けたもの（例：フラッシュ25、ベタ20）。厚みは中身の合計。部材の「材料」の欄で選べ、木取りする中身ごとに木取りする。切り代はこの部材だけに足す | |
| 中身 | 材料グループに入れる「材料 × 1部材あたりの枚数」の並び（例：芯材15×1・メラミン1×2・ラワン4×2）。順番や芯材・表面材の区別は持たない | |
| 初めの形 | 材料グループを追加するときに選ぶひな形（フラッシュ／ベタ／空）。自動の名前の頭になる（フラッシュ25・ベタ20・グループ20） | |
| ベタ | 材料グループの初めの形の1つ（材料×1＋メラミン1×2。例：ベタ20＝ラワン18×1＋メラミン1×2） | |
| 木取りしない | 材料に付ける印（例：芯材12）。厚みの計算には使うが、木取りの計算には入れない | |
| 採用 | 手持ちの行の表示。その行の材料を全部使う。一部なら「◯枚採用（残り◯枚）」 | |
| 不採用 | 手持ちの行の表示。その行の材料を1枚も使わない | |
| 部材が収まりません | 手持ちの行の表示。1枚も使わず、入らない部材が残っている | |
