# kidori 取扱説明書

最終更新：2026-09-29（第2.5版）

---

## 1. はじめに

### 何ができるアプリか

kidori（木取り）は、家具の部材の寸法を入れると、パネルソーで切る寸法（木取り寸法）を出し、材料（3×6・4×8 など）にどう並べれば歩留まり良く切り出せるかを計算するアプリです。

- 部材の寸法は、数字のほかに「全体.W − 側板.W × 2」のような式でも入れられます。全体の寸法を変えると、ほかの部材もついてきます
- 寸法表で、部材ごとの仕上がり寸法を一覧で見られます
- 木取りの画面で、材料ごとの配置図・必要な材料の枚数・歩留まりを見られます
- 切りながら、配置図の下のチェックで「切った部材」を付けていけます
- フラッシュ25（芯材15×1 ＋ メラミン1×2 ＋ ラワン4×2）のように材料を組み合わせたものを「材料グループ」として登録できます。材料グループの部材は、木取りする中身ごとに木取りします。2種類の中身を2枚重ねて切ることもできます
- 芯材のようにパネルソーで切らない材料は「木取りしない」にしておくと、厚みの計算にだけ使い、木取りには入れません
- 材料のサイズで「自由入力」を選ぶと、手元にある材料（手持ち）のサイズと枚数を登録して、その範囲で木取りすることもできます
- 仕事をファイルにして LINE などで職場の人に送ったり、全部の仕事をバックアップのファイルにしておいたりできます

### 開き方

スマホのブラウザ（iPhone は Safari、Android は Chrome）で次のアドレスを開きます。

`https://kobayashikenpa.github.io/kidori/`

### ホーム画面に追加する

アプリのように、ホーム画面のアイコンから開けるようにしておくと便利です。

**iPhone（Safari）**

1. 上のアドレスを Safari で開く
2. 画面下の共有ボタン（四角から上向きの矢印）を押す
3. 「ホーム画面に追加」を押す
4. 右上の「追加」を押す

**Android（Chrome）**

1. 上のアドレスを Chrome で開く
2. 右上の「︙」を押す
3. 「ホーム画面に追加」（または「アプリをインストール」）を押す

### データの保存場所と注意

- 入れた仕事・部材・設定は、**そのスマホの中（ブラウザの中）に自動で保存**されます。保存ボタンはありません
- ほかの人のスマホや、別のブラウザとは自動では共有されません。ほかの人に渡すときは「この仕事を送る」でファイルにして送ります（4章「仕事を送る・受け取る」）
- **ブラウザの「履歴とWebサイトデータを消去」などをすると、仕事がすべて消えます**。元に戻す方法はありません。ときどき「バックアップを書き出す」でファイルに残しておくと安心です（4章「バックアップ」）
- iPhone では、ホーム画面のアイコンから開いたときと Safari で開いたときで、保存場所が別になることがあります。いつも同じ開き方で使ってください
- 電波の無い場所では開けないことがあります
- 画面の上に「保存できませんでした（端末の空き容量などを確かめてください）」と出たら、スマホの空き容量を確かめてください

## 2. 画面の見方

画面の一番上に、いま開いている仕事の名前が出ます（開いていなければ「仕事を開いていません」）。

画面の下に、5つのタブが並んでいます。押すと画面が切り替わります。

| タブ | すること |
|---|---|
| 仕事 | 仕事（家具1台・1件の注文）を作る・開く・名前を変える・コピー・削除・送る。バックアップの書き出しと、ファイルからの取り込み |
| 部材 | 部材（側板・天地板・棚板など）を入れる・直す |
| 寸法表 | 部材ごとの仕上がり寸法の一覧。仕上がりの「完了」を付ける |
| 木取り | 材料への並べ方（配置図）・必要な材料の枚数・歩留まり。切り出しチェックを付ける |
| 設定 | 刃厚・端切り・切り代・切り方、調整寸法、材料、材料グループ、配色 |

- 仕事を開いていないときは、「仕事」以外のタブは押せません
- 見出しの横に「ⓘ」があるところは、見出しを押すと説明が出ます。もう一度押すか、ほかのところを押すと消えます

### 数字の入れ方（数字キー）

刃厚・端切り・材料の厚み・枚数などの数字の欄を押すと、スマホのキーボードではなく、画面の下にアプリの**数字キー**が出ます。

- 「⌫」で1字消す、「クリア」で全部消す、「決定」で決めて閉じます
- 名前やメモなど文字の欄は、ふつうのキーボードで入れます

## 3. 最初の準備（設定）

設定は**仕事ごと**に持ちます。新しい仕事を作ると、**最後に変えた設定**がそのまま引き継がれます。最初に一度、よく使う値にしておくと、あとの仕事が楽になります。

「設定」タブを開きます。

### 刃厚・端切り・切り代・切り方

| 項目 | 初めの値 | 意味 |
|---|---|---|
| 刃厚 | 3mm | 1回切るごとに刃で削れて消える幅 |
| 端切り | 5mm | 材料の端を最初に切り落として矩を出す幅（刃厚を含む） |
| 切り代（材料グループのみ） | 10mm | あとで削り仕上げるための余分。**材料グループ（フラッシュ25・ベタ20 など）の部材だけに足します**（材料を1つだけ選んだ部材は 0） |
| 切り方 | 縦切り優先 | 縦切り優先／横切り優先／おまかせ |

切り代は「0mm」「5mm」「10mm」のボタンで選ぶか、下の欄に数字を入れます。

**切り方**

- **縦切り優先**：材料を縦長に置き、右側の長手を端切りしてから、右から長手方向の帯を切り出して切り分けます。縦長の端材が残りやすい切り方です
- **横切り優先**：材料を横長に置き、下側の長手と右側の妻手を端切りしてから、右から妻手方向の帯（妻手の幅いっぱい）を切り出して切り分けます。妻手の幅のままの余りが左に残ります
- **おまかせ**：両方を計算して、必要な材料が少ないほうを使います。同じなら、一番大きい端材が大きく残るほうを使います

どの切り方でも、部材は右上から左下へ詰め、余りは左下に残ります。切り方は木取りの画面でも変えられます。

### 調整寸法（逃げ・ほぞなど）

仕上がり寸法を少し短くしたり長くしたりする寸法を、名前と寸法で登録しておき、式の中で使います（例：棚板の幅を「天地板.W − 逃げ1」にする）。

初めから「逃げ0.5」「逃げ1」が入っています。

**追加する**

1. 「名前」に名前を入れる（例：ほぞ）
2. 「寸法」に寸法を入れる（例：15）
3. 「追加」を押す → 「ほぞ15」として登録されます

- 名前か寸法を変えるときは、その行の「編集」を押し、直して「変える」を押します。使っている式もついてきます
- 1つ消すときは、その行の「削除」→「削除する」。式で使っている部材があれば、確認のときに名前が出ます（消すと、その式は「削除した調整寸法を使っています」のエラーになります）
- まとめて消すときは「選んで削除」→ 消すものを押してチェック →「選んだ◯件を削除」→「削除する」

### 材料

材料は**材料名と厚み**で登録します。サイズ（3×6・4×8 など）は、ここではなく木取りの画面で選びます。

初めから次の25の材料が入っています。一覧は材料名ごとの見出し（「ラワン」「シナ」など）でまとめて出ます。

| 材料名 | 厚み（mm） |
|---|---|
| メラミン | 1 |
| ラワン | 2.5・3・4・5.5・9・12・15・18・21・24・30 |
| シナ | 2.5・3・4・5.5・9・12・15・18・21・24・30 |
| ポリ | 2.5・4 |

**追加する**（例：フラッシュの芯材 15mm を足す）

1. 「材料名」を入れる（例：芯材）
2. 「厚み」を入れる（例：15）。厚みを入れないと追加できません
3. パネルソーで切らない材料なら、「木取りしない（例：芯材）」を押してチェックを付ける
4. 「追加」を押す

- 「木取りしない」を付けた材料（例：芯材12・芯材15、桟の枠など）は、一覧に「木取りしない」の印が出ます。**厚みの計算には使いますが、木取りの計算には入りません**
- あとから足した材料は、足した順に上に並び、初めから入っている材料はその下に並びます
- 一覧の行には、使っている部材と、中身に使っている材料グループが出ます
- 「編集」「削除」「選んで削除」は調整寸法と同じです。「編集」では「木取りしない」も付け外しできます
- 消す材料を使っていると、確認のときに知らせます。部材は「材料が未設定」になり、式で使っていた厚みはエラーになります。材料グループの中身に使っていれば、その中身が外れて、材料グループの厚みが変わります

### 材料グループ

材料を組み合わせたものを、名前を付けて登録します。登録した材料グループは、部材の「材料」の欄で選べます。

- 例：フラッシュ25 ＝ 芯材15×1 ＋ メラミン1×2 ＋ ラワン4×2
- 例：ベタ20 ＝ ラワン18×1 ＋ メラミン1×2
- 中身は「材料 × 1部材あたりの枚数」を並べたものです。厚みは中身の合計が自動で出ます
- 木取りでは、**木取りする中身ごと**に木取りします（例：ベタ20 の側板2枚 → ラワン 18mm を2枚・メラミン 1mm を4枚）。「木取りしない」材料（芯材など）は木取りに入れません
- 材料グループの中からは、新しい材料を足せません。中身に使う材料（例：芯材15）は、**先に上の「材料」で足しておきます**

**追加する**（例：フラッシュ25。先に「芯材 15mm（木取りしない）」を材料に足しておく）

1. 「初めの形」を選ぶ（例：「フラッシュ」）
   - 「フラッシュ」：空欄 ×1 ＋ メラミン1 ×2 ＋ ラワン4 ×2
   - 「ベタ」：空欄 ×1 ＋ メラミン1 ×2
   - 「空」：中身なし
2. 空欄の行（「（材料を選ぶ）」）を押して、材料を選ぶ（例：芯材 15mm（木取りしない））。選ぶ欄は「木取りしない」と「木取りする：ラワン」のように材料名ごとに分かれています
3. 枚数を確かめる。枚数は「1部材あたりの枚数」です
   - 中身を増やすときは「＋ 中身を足す」、減らすときはその行の「削除」
   - 同じ材料は2行に入れられません（枚数でまとめます）
4. 「厚み 芯材15×1 ＋ メラミン1×2 ＋ ラワン4×2 ＝ 25」のように厚みが出るのを確かめる
5. 「名前」は、初めの形の名前と厚みで「フラッシュ25」のように自動で入ります（「ベタ」なら「ベタ20」、「空」なら「グループ20」）。中身を変えると名前もついてきます。変えたいときだけ書き換える（消して空にすると自動の名前に戻ります）
6. 「追加」を押す

- 空欄の行が残っていると「空欄の行の材料を選んでください（選ばないと追加できません）」と出ます
- 一覧の行には、厚みの内訳・「重ね切り」・使っている部材が出ます。中身が無いときは「中身がありません（編集で選んでください）」と出ます
- 「編集」「削除」「選んで削除」は材料と同じです
- 以前の版で登録したフラッシュは、材料グループに移っています。芯材の厚みは「芯材15（木取りしない）」のような材料として材料の一覧に加わり、中身に入っています。名前・厚み・寸法・木取りの結果は変わりません

**重ねて切る（2枚重ね）**

- 木取りする中身の2種類を1枚ずつ重ねて（例：メラミン1枚＋ラワン1枚）、1回で切る設定です。「重ねて切る（2枚重ね）」を押してチェックします
- 木取りする中身が**2種類で、枚数が同じ**とき（例：メラミン ×2・ラワン ×2）に選べます。選べないときは「木取りする中身が2種類で、枚数が同じときに選べます」と出ます。新しく登録するときは、選べるなら初めからチェックが付いています
- 木取りの画面では、重ねる2つの材料を1つの配置図に並べます（「メラミン1＋ラワン4（重ね切り）」）
- 重ねて切る分のサイズは、木取りの画面の組の行で選びます。2つの材料は同じサイズとして重ねます

### 配色

「端末に合わせる」「ライト」「ダーク」から選べます。この設定だけは仕事ごとではなく、そのスマホ全体に効きます。

## 4. 仕事を作る

家具1台（1件の注文）を1つの仕事にします。「仕事」タブで操作します。

### 新しい仕事を作る

1. 「＋ 新しい仕事を作る」を押す
2. 名前を入れる（例：食器棚 W1200。空欄なら「名前のない仕事」）
3. 「作って開く」を押す → 部材の画面が開きます

新しい仕事には、最後に変えた設定（刃厚・端切り・切り代・切り方・調整寸法・材料・材料グループ）が入っています。

### 見本で試す

使い方を試したいときは、画面の下の「見本（本棚 W900）を追加」を押します。

- 本棚 W900 の部材（全体・側板・天地板・棚板・背板）が入った仕事ができます。側板・天地板・棚板は材料グループのフラッシュ25（芯材15×1 ＋ メラミン1×2 ＋ ラワン4×2）、背板はラワン4 です
- 今の設定に芯材15（木取りしない）・フラッシュ25 が無ければ足します
- 材料は 3×6 になっています。初めの設定のままなら、木取りの画面で「メラミン1＋ラワン4（重ね切り）」が5枚、「ラワン 4mm」が1枚（背板）と出ます
- 不要になったら削除してかまいません

### 保存した仕事を操作する

「保存した仕事」に、更新の新しい順に並んでいます。

- 開く：「開く」（いま開いている仕事は「続きを開く」と「開いている」の印）
- 名前を変える：「名前を変える」→ 新しい名前を入れて「名前を決める」
- コピー：「コピー」→「◯◯ のコピー」が一番上にできます。似た家具を作るときに使います（切り出しチェックの記録は写りません）
- 削除：「削除」→「消す」。**元に戻せません**

### 仕事を送る・受け取る

同じ仕事を職場の人のスマホでも見られるように、仕事をファイルにして LINE などで送ります。

**送る**（例：本棚 W900 を送る）

1. 「保存した仕事」で、送る仕事（本棚 W900）の「この仕事を送る」を押す
2. スマホの共有の画面が出るので、送り先（LINE・メール・AirDrop など）を選ぶ
3. LINE なら、送る相手を選んで送る

- 「本棚W900.kidori.json」のような名前のファイルが送られます
- 共有の画面が出ないスマホでは、ファイルがスマホに保存され、「ファイルを保存しました。LINE などからこのファイルを送ってください」と出ます。LINE のトークでそのファイルを選んで送ってください
- 共有の画面を閉じたときは、何も起きません
- **送るファイルには、切り出しチェックと寸法表の「完了」のチェックは入りません**。受け取った人の仕事は、チェックが何も付いていない状態から始まります
- 部材・設定と、その仕事で使っている材料・材料グループ・調整寸法は入ります

> **注意**：ファイルを持っている人は、誰でも中身（仕事の名前・部材・寸法）を見られます。送り先をまちがえないようにしてください。

**受け取る（iPhone）**

LINE で届いたファイルは、まず「ファイル」に保存してから kidori で選びます。

1. LINE のトークで、届いたファイルを押す
2. 共有のボタン（四角から上向きの矢印）を押し、「"ファイル"に保存」を押す
3. 保存する場所を選んで「保存」を押す
4. kidori の「仕事」タブを開き、画面の下の「ファイルから取り込む」を押す
5. 出てきた一覧から「ファイルを選択」を押す
6. さっき保存したファイルを押す
7. 「共有された仕事：本棚 W900（部材 5種類・9枚）」のような確認が出るので、「取り込む」を押す → その仕事が開きます

**受け取る（Android）**

1. LINE のトークで、届いたファイルを押して、スマホに保存する（ふつうは「ダウンロード」に入ります）
2. kidori の「仕事」タブを開き、画面の下の「ファイルから取り込む」を押す
3. ファイルを選ぶ画面で、保存したファイル（「ダウンロード」の中など）を押す
4. 確認が出るので「取り込む」を押す → その仕事が開きます

- LINE の版によって、ボタンの名前や場所が少しちがうことがあります
- 取り込んだ仕事は、自分の仕事に**コピーとして足されます**。今ある仕事は変わりません（上書きしません）。同じ名前の仕事があるときは「本棚 W900 のコピー」のような名前になります
- 取り込んだあとは、送った人と受け取った人で別々に直します。片方で直しても、もう片方には写りません。直した内容を渡すときは、もう一度送ってください
- やめるときは確認で「やめる」を押します。何も変わりません
- kidori のファイルでないときや、壊れたファイルのときは「読み込めませんでした」と出ます。このときも、今の仕事は何も変わりません

### バックアップ

スマホを買い替えるときや、ブラウザのデータが消えたときのために、**全部の仕事**を1つのファイルにしておけます。

**書き出す**

1. 「仕事」タブの画面の下の「バックアップを書き出す」を押す
2. 共有の画面で、「"ファイル"に保存」や LINE（自分だけのトークなど）を選んで保存する

- 「kidori-バックアップ-2026-09-29.json」のような名前のファイルになります
- バックアップには、全部の仕事（切り出しチェックや「完了」のチェックも含めて）と、最後に使った設定が入ります
- 共有の画面が出ないスマホでは、ファイルがスマホに保存され、「ファイルを保存しました。…」と出ます
- バックアップのファイルも、持っている人は誰でも中身を見られます。取り扱いに注意してください

**戻す（取り込む）**

1. バックアップのファイルを、上の「受け取る」と同じように「ファイル」（Android は「ダウンロード」など）に置いておく
2. 「ファイルから取り込む」を押し、バックアップのファイルを選ぶ
3. 「バックアップの仕事：2件（本棚 W900・食器棚）」のような確認が出るので、「追加する」を押す
4. 「2件の仕事を追加しました」と出ます

- 今ある仕事に**足します**。消したり上書きしたりはしません。同じ名前の仕事があるときは「◯◯ のコピー」として足します
- 切り出しチェックや「完了」のチェックも、書き出したときのまま戻ります
- 仕事が1つも無いスマホに戻したとき（新しいスマホに移すとき）は、最後に使った設定も戻ります。仕事があるときは、今の設定のままです
- 開いている仕事は変わりません。戻した仕事は「保存した仕事」から開いてください

---

## 5. 部材を入れる

「部材」タブで、切り出す部材を入れます。寸法は組み立てたときの向きで **W（幅）・H（高さ）・D（奥行き）** で入れます。

### 部材の一覧

- 1部材1枚のカードで、名前・枚数・材料・W・H・D が出ます。厚みにあたる寸法には「・厚み」が付きます
- 困りごとがあると、カードに「材料が未設定」「厚みが合わない」「式のエラー」の印が出ます
- 木取りしない材料（芯材など）を選んだ部材には「木取りしない」の印が出ます
- カードを押すと編集、「＋ 部材を追加」で新しい部材を足します

### 部材を足す（例：本棚の棚板）

1. 「＋ 部材を追加」を押す
2. 「名前」を入れる（例：棚板）。同じ名前は付けられません。式の中で「棚板.W」のように使います
3. 「枚数」を入れる（例：4）
4. 「材料」を選ぶ（例：フラッシュ25。下の「材料の選び方」）
5. W・H・D を入れる（下の「式の入れ方」）
6. 「厚み：H（自動）」のように厚みが自動で決まったのを確かめる
7. 「木目」を選ぶ（例：W方向）
8. 必要なら「切り代」「メモ」を入れる
9. 「追加する」を押す

直すときはカードを押し、直して「保存する」。消すときは「この部材を削除」→「削除する」。閉じるときは「閉じる」か、上の暗いところを押します（「保存する」を押さずに閉じると、直した内容は残りません）。

### 材料の選び方

「材料」の欄を押すと、材料と材料グループが分かれて並びます。

- 「材料：ラワン」「材料：シナ」のように材料名ごとにまとまった材料（例：ラワン 4mm）
- 「材料グループ」の見出しの下に、材料グループ（例：フラッシュ25（厚み 25mm））
- いちばん下に「＋ 材料グループを作る」

新しい部材は、並びの最初の木取りする材料が選ばれた状態で始まります。材料グループを選ぶと、欄の下に「厚み 芯材15×1 ＋ メラミン1×2 ＋ ラワン4×2 ＝ 25」のように中身が出ます。

木取りしない材料（芯材など）や、中身がすべて木取りしない材料グループを選ぶと、「木取りしない材料なので、木取りの計算には入りません」と出ます。

**部材の画面から材料を直す**（例：フラッシュ25 の中身を確かめて直す）

1. 「材料」の欄でフラッシュ25 を選んでおく
2. 欄の横の「編集」を押す → 部材の編集の上に「設定：材料グループの編集」が開きます（材料を選んでいるときは「設定：材料の編集」）
3. 中身や名前を直す
4. 「変える」を押す → 設定に入り、部材の編集に戻ります

**部材の画面から材料グループを作る**（例：ベタ20 を作って棚板に使う）

1. 「材料」の欄で「＋ 材料グループを作る」を選ぶ → 「設定：材料グループの追加」が開きます
2. 3章「材料グループ」の「追加する」と同じように、初めの形・中身・名前を入れる（例：「ベタ」、空欄の行にラワン 18mm）
3. 「追加」を押す → 部材の編集に戻り、作った材料グループ（ベタ20）が選ばれています

- どちらも、やめるときは「やめる」を押します。部材の編集で入れかけた内容は残ったままです
- ここで直した材料・材料グループは、設定の画面で直したのと同じです（ほかの部材にも効きます）
- 材料・材料グループの削除は、設定の画面で行います

### 寸法だけの行（枚数0）

「全体」のように、切り出さずに家具の外寸だけを持つ行は、枚数を 0 にします。材料・厚み・木目は入れなくてかまいません。ほかの部材の式で「全体.W」のように使います。

### 式の入れ方（ボタン入力）

W・H・D の欄を押すと、キーボードは出ずに、式を作るボタンが並びます。

**ボタンの並び**

- 上の欄（タブで切り替え）
  - 「部材」：部材名を押す → その部材の W・H・D（値つき）を押すと、式に「側板.W」のように入ります。「◀ 戻る」で部材名の並びに戻ります
  - 「厚み」：その部材で選んでいる材料・材料グループの厚み（例：ラワン4、フラッシュ25）
  - 「調整寸法」：逃げ1・ほぞ15 など
- 下の数字と記号：0〜9、「.」、「+」「−」「×」「÷」「(」「)」
- 「◀」「▶」：式の中の入れる位置を左右に動かす
- 「1字消す」：入れる位置の前の1つを消す（「側板.W」のような部材の寸法は1つの塊として消えます）
- 「全部消す」：式を全部消す
- 「完了」：ボタンを閉じる

**例：本棚の天地板の W（全体の幅から側板2枚分を引く）**

1. 天地板の「W」の欄を押す
2. 「部材」タブで「全体」を押し、「W」を押す
3. 「−」を押す
4. 「部材」タブで「側板」を押し、「W」を押す
5. 「×」を押す
6. 「2」を押す
7. 欄の上に「仕上がり 850」と出るのを確かめて「完了」を押す

- 欄の上の1行には、ふだんは仕上がりの値が出ます。式にまちがいがあると、同じ行に赤でエラーが出ます（押すと全文）
- 部材の厚みは、数字で「25」と入れるより「厚み」タブのボタン（例：フラッシュ25）で入れるのがおすすめです。材料や材料グループの厚みを変えたとき、式もついてきます。部材の材料を変えたときも、自動で置き換わります（下の「材料を変えたとき」）
- 参照している部材の寸法を変えると、その部材を使っている式の値も自動で変わります
- 部材の名前を変えると、ほかの部材の式の中の名前もついてきます

### 厚み

- W・H・D のうち、材料の厚み（材料グループなら中身の合計の厚み）と同じ値の寸法を、自動で「厚み」にします。ふだんは「厚み：W（自動）」と表示だけ出ます
- 同じ値の寸法が2つ以上ある（例：細い桟）ときなどは、「自動／W／H／D」の選ぶ欄が出ます。どれが厚みか押して選びます
- **厚みにあたる寸法が材料の厚みと合わないと、保存できません**（「厚みの寸法（W=18）が材料の厚み 25 と合いません」など）。寸法か材料を直してください

### 材料を変えたとき

部材の「材料」を変えると、その部材の式に入っている前の材料の厚みを、新しい材料の厚みに自動で置き換えます（例：棚板の材料をフラッシュ25 からフラッシュ22 に変える）。

- 置き換えたときは、材料の欄の下に「H の式のフラッシュ25 をフラッシュ22 に置き換えました」のように出ます
- 置き換えたくないときは「元に戻す」を押すと、式が前のままに戻ります（材料は新しいまま）
- 置き換わるのは、「厚み」タブのボタンで入れた厚みだけです。数字で「25」と入れた式は変わりません
- 変わるのはその部材の式だけです。ほかの部材の式は変えません
- 「保存する」を押すまでは決まりません

### 木目

材料の面になる2つの寸法のどちらに木目を通すかを選びます（例：側板なら「H方向」「D方向」「どちらでもよい」）。「どちらでもよい」にすると、木取りで回して置くことがあります。厚みが決まるまでは選べません。

### 切り代

- 空欄なら、材料グループの部材は設定の切り代（初めは 10。欄に「空欄＝初期値 10」と出ます）、材料を1つだけ選んだ部材は 0 です（「空欄＝0」）
- 部材ごとに変えたいときだけ数字を入れます（材料の部材でも、入れれば足します）
- 例：フラッシュ25 の天板 仕上がり W900×D600、切り代 10 → 木取り寸法 910×610（厚みには足しません）

### メモ

切り出したあとの加工（例：切り出したあとに穴あけ）などを書いておけます。寸法表にも出ます。

## 6. 寸法表を見る

「寸法表」タブで、部材ごとの**仕上がり寸法**を1部材1行の表で見られます。木取り寸法（切り代を足した寸法）は、木取りの画面で見ます。

- 列は「部材」「枚数」「仕上がり寸法 W・H・D」「完了」
- メモのある部材は、部材名の下に小さくメモが出ます。長いときは部材名を押すと全文が出ます
- 厚みが合わない部材には「厚みが合わない」、計算できない寸法には「エラー」と出ます

### 内訳を見る

寸法の数字（青）を押すと、その下に式の内訳が開きます（例：`全体.W 900 − 側板.W 25 × 2`）。もう一度押すと閉じます。

材料グループの部材の厚みを押すと、材料グループの中身が出ます（例：`フラッシュ25（芯材15×1 ＋ メラミン1×2 ＋ ラワン4×2）`、`ベタ20（ラワン18×1 ＋ メラミン1×2）`）。

### 仕上がりの完了を付ける

仕上げが終わった部材は、行の右の「完了」のチェックを押します。完了した行はグレーになります。もう一度押すと外れます。

## 7. 木取りをする

「木取り」タブで、材料ごとの配置図・必要な材料の枚数・歩留まりを見て、切りながらチェックを付けます。

画面の上に、いまの「刃厚・端切り・切り代（材料グループ）」が出ます。部材ごとに切り代を入れた部材があれば、その値も出ます。その下で**切り方**を変えられます。

### まとめ

一番上のまとめに、**全体の歩留まり**と、材料ごと（重ね切りの組ごと）の行が並びます。

- 「必要な材料 ◯枚」「歩留まり ◯%」「切り方：縦切り優先」など
- おまかせで選ばれた切り方には「おまかせで選択」の印が出ます
- 重ね切りの分は、「メラミン1＋ラワン4（重ね切り）」の組の行にだけ出ます。メラミン・ラワンの行には、ふつうに木取りする分（例：背板）だけが出ます
- 木取りしない材料（芯材など）の行は出ません。材料グループの部材は、木取りする中身の材料の行に入ります（例：ベタ20 の側板は「ラワン 18mm」と「メラミン 1mm」の行に入り、同じ材料のほかの部材と一緒に並べます）

### 材料のサイズの選び方

まとめの**行ごと**（材料の行と、重ね切りの組の行）に「材料のサイズ（押して選ぶ）」と、サイズのボタンが並びます。材料の行は「3×6」「4×8」「自由入力」、重ね切りの組の行は「3×6」「4×8」だけです（重ね切りでは自由入力・手持ちは使えません）。初めは 4×8 です。

- 「3×6」「4×8」のボタンに、それぞれで木取りしたときの枚数と歩留まりが出ます。少ないほうに「枚数が少ない」、高いほうに「歩留まりが高い」の印が付きます。押すとそのサイズになります
- 入らない部材があると「入らない ◯」の印が付きます
- 定尺以外の大きさや、手元にある材料で木取りするときは「自由入力」を押します（次の「手持ちの材料（自由入力）」）

**重ね切りの組のサイズ**：組の行（例：メラミン1＋ラワン4（重ね切り））で選んだサイズは、重ねて切る分だけに使います。2つの材料は同じサイズとして重ねます。メラミンの行・ラワンの行で選んだサイズは、その材料をふつうに木取りする分（例：背板）だけに使います。

例：「メラミン1＋ラワン4（重ね切り）」は 3×6、背板だけの「ラワン 4mm」は 4×8、のように別々に選べます。

### 手持ちの材料（自由入力）

サイズを1つ選ぶかわりに、**手元にある材料**（例：4×8 ×3枚、3×6 ×2枚、900×450 ×1枚）を行ごとに登録して、その範囲で木取りできます。大きい部材から順に、それが収まる一番小さい材料を選んで並べます。

**手持ちで木取りする**（例：背板のラワン 4mm に 3×6 が5枚ある）

1. まとめの「ラワン 4mm」の行で「自由入力」を押す → その下に「手持ちの材料（この行の分）」が開き、いまのサイズが1枚の行が入ります
2. 行のサイズ（「3×6」「4×8」「自由入力」）を押して選ぶ（例：3×6）
3. 「自由入力」を選んだときだけ、「短辺（妻手）」「長辺（長手）」を入れ、「木目 長手方向」「木目 妻手方向」のどちらかを押す
4. 「枚数」を押して枚数を入れ、「決定」を押す（例：5）
5. ほかのサイズもあるときは「＋ 手持ちを足す」を押して、2〜4 を繰り返す

- 行ごとに、その行の材料を使うかが出ます。いらない行は「削除」を押します
  - 「採用」：その行の材料を全部使う
  - 「2枚採用（残り 3枚）」：一部を使う（例：5枚のうち2枚）
  - 「不採用」：1枚も使わない（ほかの行の材料で足りている）
  - 「部材が収まりません」：1枚も使わず、しかも入らない部材が残っている（その大きさでは部材が入らない）
- 「自由入力」を選んでいる行でも、「3×6」「4×8」のボタンには、そのサイズで木取りしたときの枚数と歩留まりが出ます（比べてから選べます）。手持ちの行をすべて消すと、自由入力の前に選んでいたサイズに戻ります
- 「3×6」か「4×8」を押すと、サイズを1つ選ぶ木取りに戻ります。登録した手持ちは残るので、もう一度「自由入力」を押すとそのまま使えます
- 手持ちで木取りする行には「手持ち：4×8 ×1・3×6 ×1」のように使う枚数が出ます。1枚ごとの見出しにも「（4×8）」のように大きさが出ます
- 重ね切りの分の手持ちは、組の行の「自由入力」で登録します（2つの材料は同じサイズとして扱います）
- 切り出しチェックを付けて固定した1枚は、使った手持ちの1枚として数えます

**手持ちが足りないとき**

「ラワン 4mm が足りません（入らない部材：背板）」のように赤い知らせが出て、その下に解決策が出ます。

- 「3×6 を 1枚 足すと入ります」の横の「足す」を押すと、その材料の行の手持ちに足します
- 「切り代を 7mm にすると手持ちで入ります」のように出たときは、設定の画面で変えてください（自動では変えません）
- 足りない材料が2つ以上あるときは、材料ごとに「足す」を押してください

### 1枚ごとの配置図

まとめの下に、材料ごとの段（例：「ラワン 4mm　1枚・縦切り優先」）があり、1枚ごとのカードが並びます。

- 見出し：「1枚目 / 5枚」、歩留まり
- 「材料 910×1820・部材 ◯枚」
- 配置図：部材名と木取り寸法が書かれています。部材は右上から詰めています
- 幅が同じ部材は、なるべく同じ帯に縦に並べます（帯の幅がそろい、切りやすくなります）。ただし、そうすると必要な材料が増えるときは、枚数が少ない並べ方を使います
- 図の下の印の説明：端切りした辺（例：縦切り優先は「端切り 5mm（右）」、横切り優先は「端切り 5mm（下・右）」）、木目の向き（長手方向／妻手方向）など

### 切り出しチェック

配置図のすぐ下に、その1枚で切る部材が**切る順**に並んでいます（例：□ 側板 1810×410）。

1. 部材を1つ切ったら、その行を押してチェックを付ける
2. 最初の1つにチェックすると、**その1枚の並びが固定されます**（固定のボタンはありません）。あとで部材を足したり設定を変えたりしても、この1枚は変わりません
3. チェックした部材は配置図でグレーになり、まだ切っていない部分が「残りの材料 ◯×◯」として出ます
4. その1枚の部材をすべてチェックすると、その1枚は「切り終わり」になり、一覧から消えます

- まちがえてチェックしたときは、もう一度押すと外れます。その1枚のチェックがすべて外れると固定も外れ、今の部材で並べ直します
- 切り終わった1枚は、段の見出しの下の「切り終わり ◯枚」を押すと、グレーで開いて見られます。チェックを外すこともできます
- 重ね切りの組の1枚は、1回のチェックで重ねた2種類の材料の両方に付きます
- 固定した1枚の部材の寸法や枚数をあとで変えると、その1枚に「部材が変わっています：棚板（寸法）」のように出ます。固定はそのままです。作り直すときは、その1枚のチェックをすべて外してください
- 「必要な材料」の枚数には、切り終わった1枚は数えません

### 材料を減らせるときのお知らせ

切り代や端切りを少し小さくすると必要な材料が減るときは、「お知らせ：材料を減らせます」が出ます（例：「切り代を 7mm にすると、ラワン 4mm が 1 枚減ります（3枚 → 2枚）」）。

- 設定は自動では変えません。変えるときは設定の画面で変えてください
- 部材ごとに切り代を入れた部材は、その切り代のまま計算します

## 8. 困ったとき

| 表示・困りごと | 原因と対処 |
|---|---|
| 部材のカードに「材料が未設定」 | 材料を選んでいません。または使っていた材料・材料グループを削除しました。部材を開いて「材料」を選んでください |
| 部材が木取りの画面に出てこない。部材のカードに「木取りしない」 | 木取りしない材料（芯材など）か、中身がすべて木取りしない材料グループを選んでいます。部材の材料を選び直すか、設定の材料の「編集」で「木取りしない」を外してください |
| 材料グループの一覧に「中身がありません（編集で選んでください）」 | 中身の材料を削除したなどで、中身が1つも無くなりました。「編集」で中身を選んでください。このままでは木取りできません |
| 材料グループの中身に、使いたい材料（例：芯材12）が出てこない | 材料グループの中からは材料を足せません。先に設定の「材料」で足してください（芯材なら「木取りしない」を付ける） |
| 「空欄の行の材料を選んでください」 | 材料グループの中身に、材料を選んでいない行があります。材料を選ぶか、その行の「削除」を押してください |
| 「重ねて切る（2枚重ね）」が押せない | 木取りする中身が2種類で、枚数が同じときだけ選べます（例：メラミン ×2・ラワン ×2） |
| 手持ちの行に「部材が収まりません」 | その行の大きさには、残っている部材が入りません。大きい材料の行を足すか、「足す」を押してください |
| 「厚みが合わない」「厚みの寸法（W=18）が材料の厚み 25 と合いません」 | 厚みにあたる寸法と材料の厚みが違います。寸法か材料を直してください。直すまで保存できません |
| 部材の材料を変えたら「厚みが合わない」になった | 厚みを数字（例：25）で入れていたか、「元に戻す」を押したため、式に前の厚みが残っています。その寸法の欄を押し、「1字消す」で消して「厚み」タブから新しい材料の厚みを入れ直してください |
| 部材の材料を変えたら「◯ の式の◯◯ を◯◯ に置き換えました」と出た | 式の中の前の材料の厚みを、新しい材料の厚みに自動で置き換えました。置き換えたくないときは「元に戻す」を押してください |
| 「材料の厚み 25 と同じ寸法がありません」 | W・H・D のどれも材料の厚みと同じ値ではありません。寸法を直すか、厚みの寸法を選んでください |
| 「「◯◯」という部材はありません」 | 式で使っている部材が無いか、名前がちがいます。式を直してください |
| 「循環参照になっています（A → B → A）」 | 部材どうしがお互いの寸法を使っています。どちらかの式を数字か別の部材にしてください |
| 「計算結果が 0 以下になります」 | 引き算の結果が 0 以下です。式を直してください |
| 「削除した調整寸法を使っています」「削除した材料の厚みを使っています」 | 式で使っていた調整寸法・材料を削除しました。式の赤い部分を消して入れ直してください |
| 木取りの画面に「計算から外した部材」 | 材料が未設定・寸法のエラー・厚みが合わないなどで、木取りに入れていません。部材の画面で直すと入ります |
| 「材料に収まらない部材」 | どう回しても、材料の使える範囲（端切りの後）に入りません。寸法か材料のサイズを見直してください |
| 「◯◯ が足りません（入らない部材：…）」 | 手持ちの枚数が足りません。「足す」を押すか、まとめのその行の「自由入力」で手持ちの枚数を直してください |
| 重ね切りの分のサイズを変えたい | まとめの組の行（例：メラミン1＋ラワン4（重ね切り））でサイズを選んでください。メラミン・ラワンの行のサイズは、ふつうに木取りする分だけに効きます |
| 「切り出す部材がありません」 | 枚数と材料の入った部材がありません。部材の画面で入れてください |
| 「木取り済み（計算から除いています）」の一覧 | 以前の版で部材ごとに付けた「木取り済み」です。「外す」を押すと木取りの計算に戻ります |
| 固定した1枚に「部材が変わっています」 | 固定したあとで部材の寸法・枚数を変えました。作り直すときは、その1枚のチェックをすべて外してください |
| 仕事が消えた | ブラウザのデータを消したか、別のブラウザ・開き方で開いています。1章「データの保存場所と注意」を見てください。バックアップのファイルがあれば、「ファイルから取り込む」で戻せます（4章「バックアップ」） |
| 「保存できませんでした（端末の空き容量などを確かめてください）」 | スマホの空き容量を増やしてください |
| 「この仕事を送る」を押したら「ファイルを保存しました。LINE などからこのファイルを送ってください」 | このスマホでは共有の画面が出せないので、ファイルをスマホに保存しました。LINE のトークなどから、そのファイルを選んで送ってください |
| 「ファイルを作れませんでした」 | ファイルを作れませんでした。もう一度押してみてください |
| 「読み込めませんでした」 | kidori のファイルではないか、ファイルが壊れています。今の仕事は変わっていません。送った人にもう一度送ってもらってください |
| 「新しい版のアプリで作られたので読み込めません。アプリを開き直して新しくしてください」 | 送った人のほうが新しい kidori を使っています。kidori を閉じて開き直してから、もう一度取り込んでください |
| 取り込みの確認に「一部読めないところがあったので、読めるところだけ追加します」 | ファイルの一部が読めませんでした。「取り込む」「追加する」を押すと、読めたところだけ足します。足したあと、部材や設定を確かめてください |
| 「保存できない状態なので取り込めません」 | スマホに保存ができない状態です。空き容量を確かめてから、もう一度取り込んでください |
| 受け取った仕事にチェックが付いていない | 送る仕事には、切り出しチェックと「完了」のチェックは入りません。受け取った人が付け直してください |
| 「ファイルから取り込む」でファイルが見つからない | iPhone は LINE から「"ファイル"に保存」をしてから、「ファイルを選択」で選んでください。Android は「ダウンロード」の中を見てください |

## 9. 用語集

| 言葉 | 意味 |
|---|---|
| 仕事 | 家具1台（1件の注文）ごとの入力のまとまり。部材・材料・設定をまとめて保存する |
| 部材 | 材料から切り出すパーツ（側板、天地板、棚板など） |
| 材料 | 切り出す元の板。材料名と厚みで区別する（例：ラワン 4mm） |
| 木取りしない | 材料に付ける印。厚みの計算には使うが、木取りには入れない（例：芯材12・芯材15） |
| 材料グループ | 材料を組み合わせて名前を付けたもの（例：フラッシュ25、ベタ20）。厚みは中身の合計。木取りする中身ごとに木取りする |
| 中身 | 材料グループに入っている「材料 × 1部材あたりの枚数」（例：芯材15×1・メラミン1×2・ラワン4×2） |
| 初めの形 | 材料グループを追加するときに選ぶひな形。フラッシュ／ベタ／空 |
| 3×6／4×8 | 910×1820／1220×2440 の定尺の材料 |
| 自由入力 | 定尺以外の大きさの材料。木取りのまとめの行で選ぶと、その行の手持ちの材料を登録する |
| 長手／妻手 | 材料の長い辺／短い辺 |
| W・H・D | 組み立てたときの 幅・高さ・奥行き |
| 厚み | W・H・D のうち、材料の厚みにあたる寸法 |
| 式 | ほかの部材の寸法などを使った計算（例：全体.W − 側板.W × 2） |
| 仕上がり寸法 | 家具として仕上げたときの寸法（式の計算結果） |
| 調整寸法 | 逃げ・ほぞなど、仕上がり寸法を伸ばしたり縮めたりする寸法（例：逃げ1、ほぞ15） |
| 逃げ | 納まりを良くするためのすき間 |
| 切り代 | あとで削り仕上げるための余分。材料グループの部材だけに足す |
| 木取り寸法 | パネルソーで切る寸法（仕上がり寸法＋切り代） |
| 刃厚 | 1回切るごとに刃で削れて消える幅 |
| 端切り | 最初に材料の端を切り落として矩を出すこと（刃厚を含む） |
| 縦切り優先／横切り優先／おまかせ | 切り方。おまかせは両方を計算して、必要な材料が少ないほうを使う |
| 帯 | 最初に材料から切り出す細長い材。ここから部材を切り分ける |
| 片 | 部材1枚ぶんの切り出し。枚数2の部材なら片が2つ |
| 配置図 | 材料の上に部材を並べた図 |
| 歩留まり | 材料の面積のうち、部材（木取り寸法）に使えた割合 |
| 必要な材料 | 部材をすべて取るのに必要な材料の枚数 |
| フラッシュ | 芯材の両面に表面材を貼って厚みを作るもの。材料グループの初めの形の1つ（芯材 ×1 ＋ メラミン1 ×2 ＋ ラワン4 ×2） |
| 芯材 | フラッシュの中の材料。「木取りしない」材料として登録する（例：芯材15） |
| ベタ | 材料グループの初めの形の1つ（材料 ×1 ＋ メラミン1 ×2。例：ベタ20 ＝ ラワン18×1 ＋ メラミン1×2） |
| 重ね切り | 材料グループの木取りする中身の2種類を1枚ずつ重ねて1回で切ること |
| 手持ちの材料 | 手元にある材料のサイズと枚数（3×6・4×8・自由入力を複数）。まとめの行の「自由入力」で登録すると、その範囲で木取りする |
| 採用／不採用 | 手持ちの行の表示。その行の材料を木取りに使う（全部なら「採用」、一部なら「◯枚採用」）／1枚も使わない |
| 切り出しチェック | 配置図の下の、切った部材に付けるチェック |
| 固定 | 1枚の中で最初にチェックを付けたとき、その1枚の並びを変えないようにすること |
| 残りの材料 | 1枚の中で、まだ切っていない部材の入っている部分 |
| 切り終わり | 1枚の部材をすべてチェックし終わった状態 |
| 送る（共有） | 1つの仕事をファイルにして、LINE などでほかの人に渡すこと。チェックは入れない |
| バックアップ | 全部の仕事と最後に使った設定を、1つのファイルにしておくこと |
| 取り込む | 送られてきた仕事やバックアップのファイルを選んで、自分の仕事に足すこと。今ある仕事は変えない |
