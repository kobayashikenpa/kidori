# kidori 取扱説明書

最終更新：2026-09-30（第2.8版）

---

## 1. はじめに

kidori（木取り）は、家具の部材の寸法を入れると、パネルソーで切る寸法（木取り寸法）を出し、材料（3×6・4×8 など）にどう並べれば無駄なく切り出せるかを計算するアプリです。
部材の寸法は「全体.W − 側板.W × 2」のような式でも入れられるので、全体の寸法を変えるとほかの部材もついてきます。
切りながら、切った部材にチェックを付けていけます。

**開き方**：スマホのブラウザ（iPhone は Safari、Android は Chrome）で `https://kobayashikenpa.github.io/kidori/` を開きます。

**ホーム画面に追加**（アイコンから開けて便利です）

- iPhone：Safari の共有ボタン（四角から上向きの矢印）→「ホーム画面に追加」→「追加」
- Android：Chrome の右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）

> **データはこのスマホの中に自動で保存されます**（保存ボタンはありません）。ほかのスマホとは共有されず、ブラウザの「履歴とWebサイトデータを消去」をすると消えます。ときどき「仕事」タブの「バックアップを書き出す」でファイルに残しておくと安心です。

細かいことは、画面の見出しの横の「ⓘ」を押すと説明が出ます。この説明書では、使い始めに必要なことだけを書いています。

## 2. 使う流れ

画面の下のタブ「仕事」「部材」「寸法表」「木取り」「設定」を押して画面を移ります。ほかのタブへ行って戻っても、前に見ていた位置のままです。

### ステップ1　設定を確かめる（「設定」タブ）

設定は仕事ごとに持ちます。まずは初めの値のままで使えます。変えたいときだけ直してください。

- ［基本］：刃厚（初めは 3mm）・端切り（5mm）・切り代（10mm）・切り方（縦切り優先）
- ［材料］：ラワン・シナ・ポリ・メラミンが初めから入っています。足りない材料は「＋ 材料名を追加」、厚みを足すときはその行の［＋］
- ［材料グループ］：フラッシュ25（芯材15×1 ＋ メラミン1×2 ＋ ラワン4×2）のような組み合わせを登録します
- ［調整寸法］：逃げ0.5・逃げ1 が入っています。ほぞ15 などを足せます

芯材のようにパネルソーで切らない材料は、材料を足すときに「木取りしない」にチェックを付けます。

### ステップ2　仕事を作る（「仕事」タブ）

家具1台（1件の注文）を1つの仕事にします。

1. 「＋ 新しい仕事を作る」を押す
2. 名前を入れる（例：食器棚 W1200）
3. 「作って開く」を押す → 部材の画面が開きます

試しに触ってみたいときは、画面の下の「見本（本棚 W900）を追加」を押すと、本棚の部材が入った仕事ができます。

### ステップ3　部材を入れる（「部材」タブ）

寸法は組み立てたときの向きで **W（幅）・H（高さ）・D（奥行き）** で入れます。

1. 「＋ 部材を追加」を押す
2. 「名前」（例：棚板）と「枚数」（例：4）を入れる
3. 「材料」を選ぶ。材料名（例：ラワン）→ 厚み（例：［4］）の順に押す。フラッシュ25 などは「材料グループ」→［フラッシュ25］
4. W・H・D の欄を押し、出てきたボタンで寸法を入れる（下の例）
5. 「木目」を選ぶ（例：W方向）
6. 「追加する」を押す

**式の例（本棚の天地板の W ＝ 全体の幅 − 側板2枚分）**：W の欄を押す →「部材」タブで「全体」→「W」→「−」→「側板」→「W」→「×」→「2」→ 欄の上に「仕上がり 850」と出るのを確かめて「完了」。

- 厚みは、W・H・D のうち材料の厚みと同じ寸法が自動で選ばれます。厚みは「厚み」タブのボタン（例：フラッシュ25）で入れると、材料を変えたときも式がついてきます
- 使いたい材料が無いときは、材料の欄の横の［設定］を押します。設定の画面が重なって開くので（最初は［材料］タブ）、材料を足して閉じると、入れかけの部材の編集に戻ります
- 「全体」のように家具の外寸だけを持つ行は、枚数を 0 にします
- 直すときは部材のカードを押し、直して「保存する」を押します

### ステップ4　寸法表を見る（「寸法表」タブ）

上の［木取り］［仕上がり］のタブで切り替えます。

- ［木取り］（最初はこちら）：パネルソーで切る寸法（木取り寸法）と、切り出しの進み具合（例：2/5）
- ［仕上がり］：仕上がり寸法の一覧。仕上げが終わった部材は「完了」を押してチェックします

寸法の数字を押すと、式の内訳（例：全体.W 900 − 側板.W 25 × 2）が出ます。

### ステップ5　木取りをする（「木取り」タブ）

材料ごとの並べ方（配置図）・必要な材料の枚数・歩留まりが出ます。

1. 材料の行ごとに、サイズの「3×6」「4×8」を押して選ぶ。ボタンに枚数と歩留まりが出るので、比べて選べます
2. 配置図を見ながら切る
3. 切り終わった部材の行（例：「□ 側板 ×2枚」）を押してチェックを付ける。その1枚の中の同じ部材がまとめてチェックされます
4. 1枚の部材を全部チェックすると、その1枚は「切り終わり」になります

- **重ね切り（2枚重ね）**：フラッシュなど材料グループの部材で、違う材料（例：メラミン1＋ラワン4）を2枚重ねて1回で切ります。初めは「オン」です。重ね切りの組の行と配置図は、画面の一番上に出ます
- **手元の材料で木取りする**：材料の行で「自由入力」を押し、手元にある材料のサイズと枚数を入れます
- **重ねた板の端材**：重ね切りの余り（端材）は、ほかの部材を取るのに先に使います。このとき材料の行は「自由入力」が選ばれた表示になり、使う端材と、足りない分（例：4×8 1枚）が出ます。3×6・4×8 を押すと、足りない分のサイズが変わります。手元の材料を使うときは、中の「手持ちを入れる」を押します
- 最初のチェックを付けると、その1枚の並びは固定され、あとで部材を変えても変わりません。まちがえたときは、もう一度押すと外れます

## 3. よくある困りごと

**Q. 部材のカードに「材料が未設定」と出る**
A. 材料を選んでいないか、使っていた材料を削除しました。部材を開いて「材料」を選び直してください。

**Q. 「厚みの寸法（W=18）が材料の厚み 25 と合いません」と出て保存できない**
A. 厚みにあたる寸法と材料の厚みが違います。寸法か材料を直してください。厚みは「厚み」タブのボタンで入れると、ずれにくくなります。

**Q. 部材が木取りの画面に出てこない**
A. 「木取りしない」材料（芯材など）を選んでいるか、式のエラーなどで計算から外れています。木取りの画面の「計算から外した部材」を見て、部材の画面で直してください。

**Q. サイズのボタンに「部材が収まらない」と出る**
A. そのサイズでは入らない部材があります。大きいサイズ（4×8）を選ぶか、部材の寸法を見直してください。

**Q. 仕事が消えた**
A. ブラウザのデータを消したか、別のブラウザ・別の開き方（iPhone はホーム画面のアイコンと Safari で別になることがあります）で開いています。バックアップのファイルがあれば、「仕事」タブの「ファイルから取り込む」で戻せます。

**Q. 職場の人に仕事を渡したい**
A. 「仕事」タブで、その仕事の「この仕事を送る」を押し、LINE などで送ります。受け取った人は「ファイルから取り込む」で選びます（切り出しチェックは送られません）。

## 4. 言葉の説明

| 言葉 | 意味 |
|---|---|
| 部材 | 材料から切り出すパーツ（側板、天地板、棚板など） |
| 材料 | 切り出す元の板。材料名と厚みで区別する（例：ラワン 4mm） |
| 材料グループ | 材料を組み合わせたもの（例：フラッシュ25 ＝ 芯材15×1 ＋ メラミン1×2 ＋ ラワン4×2）。厚みは中身の合計 |
| 仕上がり寸法 | 家具として仕上げたときの寸法 |
| 木取り寸法 | パネルソーで切る寸法（仕上がり寸法＋切り代） |
| 切り代 | あとで削り仕上げるための余分。材料グループの部材だけに足す（初めは 10mm） |
| 調整寸法 | 逃げ・ほぞなど、式で足し引きする寸法（例：逃げ1、ほぞ15） |
| 端切り | 最初に材料の端を切り落として矩を出すこと（刃厚を含む） |
| 刃厚 | 1回切るごとに刃で削れて消える幅 |
| 重ね切り | 材料グループの部材で、違う材料を2枚重ねて1回で切ること |
| 長手／妻手 | 材料の長い辺／短い辺 |
| 歩留まり | 材料の面積のうち、部材に使えた割合 |
